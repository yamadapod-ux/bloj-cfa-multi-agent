# Bear's Notes — NVDA (2026-04-24)

## Methodology

ใช้ **Downside Scenario Analysis** เป็น primary framework สร้าง 4 scenarios พร้อม probability เพื่อคำนวณ probability-weighted EV และ **Kelly Criterion** สำหรับ optimal position sizing จาก risk/reward จริง ใช้ **CFA Behavioral Finance** เพื่อระบุ cognitive biases ที่ Emma และ Quinn อาจมี challenge ต้องมีเหตุผล CFA รองรับทุกข้อ ไม่ใช่ perma-bear

## Challenges & Debates

### Challenge 1: CUDA Moat Durability
**Bear's Argument:**
CUDA moat ที่ Emma ให้ "Wide" rating กำลังถูก erode ใน **inference workload** ซึ่งกำลังจะใหญ่กว่า training workload ใน 2-3 ปี Custom ASIC ของ hyperscalers ทำ inference ได้ถูกกว่าและเร็วกว่า GPU อย่างมีนัย:
- Google TPU v5e: $0.35/hr vs NVDA A100 $2.00/hr สำหรับ inference
- Amazon Trainium2: AWS claim 4× better price-performance vs GPU
- Meta MTIA: deployed ใน production สำหรับ recommendation system แล้ว

**Emma's Counter:**
Training workload ยังเป็น primary demand driver และ CUDA ecosystem มี software depth ที่ ASICs ไม่สามารถ replicate ใน near-term Switching cost สูงมากสำหรับ ML research teams

**Bear's Rebuttal:**
Emma assume training dominance ตลอดไป แต่ถ้า model efficiency เพิ่ม 10× (DeepSeek-effect) training compute demand จะลด inference จะ dominate และ ASICs ชนะในตลาดนั้น

**Result:** เพิ่ม ASIC disruption เป็น Top Risk #1, probability 35% ใน 3 ปี

### Challenge 2: Historical Sharpe Distortion (vs Quinn)
**Bear's Argument:**
Quinn รายงาน Historical Sharpe 1.70 แต่นี่คือ AI boom 2023-2024 distortion NVDA ขึ้น 800% ในช่วงนั้น ซึ่ง extreme outlier event นักลงทุนที่ anchor กับ Sharpe 1.70 กำลัง experiencing **Recency Bias**

**Quinn's Response:**
ยอมรับ — เพิ่ม Forward Sharpe 0.40 ใน analysis และระบุ limitation ชัดเจน

**Result:** Quinn เพิ่ม Historical vs Forward Sharpe ใน table ทำให้ risk picture ชัดขึ้น

### Challenge 3: Probability-Weighted EV vs Emma's DCF Target
**Bear's Argument:**
Emma's DCF target $130 ใช้ assumptions ที่ optimistic:
- Terminal Growth 4% สำหรับ semiconductor? GDP growth global เฉลี่ย 3%
- Revenue Growth 25% Y1-Y3 ถ้า hyperscaler capex cut จะเหลือ 5-10%

Sensitivity analysis:
```
WACC +150bps (จาก 10.5% → 12%) + Terminal Growth 3%:
Fair Value = ลดลงเหลือ ~$75-85

Probability-Weighted EV ($118.75) vs Current Price ($110) = +8%
Risk/Reward = +8% upside / -23% downside (to stop $85) = 0.35:1 ← ต่ำมาก
```

**Emma's Counter:**
DCF ใช้ mid-case assumptions ไม่ใช่ bull case Sensitivity range $87-$148 cover scenarios ส่วนใหญ่

**Result:** Charlie ตัดสินใจใช้ Staged Entry แทน full position เพื่อปรับ average cost

## Scenario Analysis (Full)

| Scenario | Probability | Catalyst | Price | Return |
|----------|-------------|---------|-------|--------|
| **Bull** | 25% | AI capex ขยายต่อเนื่อง + Sovereign AI + Robotics | $160 | +45% |
| **Base** | 40% | Steady growth, some competition | $130 | +18% |
| **Bear** | 25% | Hyperscaler capex cut + ASIC scale-up | $85 | -23% |
| **Extreme** | 10% | AI winter / Taiwan conflict / Regulatory break-up | $55 | -50% |

**Probability-Weighted EV:**
= ($160 × 0.25) + ($130 × 0.40) + ($85 × 0.25) + ($55 × 0.10)
= $40 + $52 + $21.25 + $5.50
= **$118.75** (+8% จาก $110)

**Kelly Criterion:**
```
p = P(Bull + Base) = 0.65 (win probability)
b = avg win / avg loss = $22.5 (avg upside) / $25 (to stop $85) = 0.90
f* = (p×b − (1−p)) / b = (0.65×0.90 − 0.35) / 0.90 = (0.585 − 0.35) / 0.90 = 26%
Half-Kelly = 13% → cap ที่ 7-8% จาก risk management perspective
```
