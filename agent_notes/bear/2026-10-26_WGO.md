### 1.3 Mid-cycle 6.92% ไปถึงได้จริงไหม?
- **Regression ของ Quinn** (n=7, R² 0.84): 6.92% ≈ **~407K units** (ไม่มี savings) หรือ ~385K + net savings ~1pp · RVIA 2027F **285K** → ต้องโต **+35–43%** จากระดับ 2027
- Industry เคยอยู่เหนือ 400K เฉพาะปี 2018 (483,672), 2019 (406,070), 2020 (430,412) และช่วงบูม 2021–22 (Quinn §4a, [RVIA Dec-2019](https://www.rvia.org/news-insights/rv-shipments-december-2019))
- **ช่วงเดียวในข้อมูลที่ rate regime ใกล้ปัจจุบันคือ 2023–25** (หลัง Fed ขึ้นดอกเบี้ย): industry เฉลี่ย **330K** (313,174 / 333,733 / 342,220) → regression ให้ margin **4.0%** · บวก net savings 0.5–0.75pp → **4.5–4.75%**
- Residual บ่งชี้ structural break: เส้นปี FY19 (7.82% @ 406K) ถ้าใช้ slope 0.0377pp/K จะทำนายได้ ~5.3% @ 339K แต่ FY25 ทำได้จริงแค่ ~2.2% → ห่าง **~3pp** ซึ่งตรงกับ mix shift ไป motorhome และ pricing ที่แย่ลง
- **Bear verdict ข้อ 1:** ROIC ที่แย่ลงเป็น**ส่วนผสม** คือ ~60% cyclical (volume) + ~40% structural (mix, pricing, floorplan regime) · mid-cycle ที่ Bear ใช้เป็น central = **4.75%** (ช่วง 4.5–5.0%) ไม่ใช่ 6.92% · ค่า 6.92% เป็นไปได้ แต่ต้องมี **rate cut + volume ≥385K + savings เต็ม** พร้อมกัน → Bear ใส่ไว้ใน bull เท่านั้น (และยัง cap ที่ 6.0%)

**Fix #3 (mid-cycle sensitivity, Blended 40/30/30 โดยใช้ Bear FV $36.02):**
```
ถ้า mid-cycle margin ต่างไป −31% / −17% / +15% (6.92% → 4.75% / 5.77% / 7.95%)
→ Blended FV เปลี่ยนเป็น $43.12 / $50.70 / $66.96 (base ตาม lock $59.26)
```
*วิธีคำนวณ: Emma FV ต่อ 1pp ≈ $11.79 (จากค่า 1.6 ของ Emma: 6.92% → $72.54, 5.77% → $58.98) · Quinn base ใช้ matrix ของ Quinn (5% → $51.96, 6% → $64.40, 8% → $89.30) โดย bull ปรับตามสัดส่วนและ bear ของ Quinn คงเดิม · Bear FV คงเดิมเพราะใช้ mid-cycle ของตัวเองอยู่แล้ว → **ค่าประมาณ**: Emma/Quinn ควรรันจริงใน script*
