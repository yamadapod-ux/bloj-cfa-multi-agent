**การสืบสวน:** ทั้งคู่ใช้ EV/Revenue framework บน FY26 guide เดียวกัน ($14.0B midpoint) — gap ไม่ได้มาจาก revenue assumption แต่มาจาก **multiple anchor**

**Emma's framework (เทียบกับ market-implied forward multiple 7.44x) มี rigor สูงกว่า** เพราะไม่ anchor กับ trailing multiple ตรงๆ — Bear เห็นด้วยกับทิศทางของ Emma มากกว่า Quinn ในประเด็นนี้ แม้ Emma's 7.0x เองก็เป็น judgment call เช่นกัน (ไม่ใช่ derived จาก independent model)

**Emma-Quinn ตอบยังไง:** ทั้งคู่ transparent เรื่อง assumption ของตัวเองอยู่แล้ว (Emma ระบุชัดว่า "conservatism adjustment" ส่วน Quinn ระบุ multiple เป็น "assumption flagged") — ไม่มีใครอ้างว่าตัวเลขตัวเองถูกต้องแน่นอน ปัญหาไม่ใช่ dishonesty แต่คือ Quinn's 45%-probability Base case ยึดโยงกับ multiple ที่ไม่มี independent justification (แค่ "current 9.07x") มากกว่า Bear คาดหวัง

**ผลลัพธ์:** Bear เสนอ reconcile ด้วยการใช้ multiple anchor แบบ Emma (เทียบ market-implied forward) แต่ยัง probability-weight สาม scenario ตามแนวทาง Quinn — ดู Bear's own P-W EV ด้านล่าง

### 2. Growth-Rate Denominator Inconsistency `[CFA L2: Equity Valuation — Reverse DCF]`

ทั้ง Emma's Growth MOS heuristic และ Quinn's formal Reverse DCF ใช้ "FY26 guided organic growth 30-32%" เป็นตัวหาร (denominator) ของ ratio test — แต่ revenue dollar math เอง (FY26 guide midpoint $14.0B ÷ TTM $11.48B) ให้ total growth เพียง **~21.9%** ไม่ใช่ 30-32%

- ถ้า FY26 guide คำนวณเทียบ FY25 actual ($10.23B) → total growth = 14.0/10.23-1 = **~36.9%**
- ทั้งสองตัวเลขนี้ต่างจาก "30-32% organic" ที่ Atlas ระบุใน package — ส่วนต่างน่าจะมาจาก definition gap (organic excludes FX/M&A, total revenue รวมทุกอย่าง) แต่ **ไม่มีใครใน package reconcile ตัวเลขนี้อย่างชัดเจน**

**Sensitivity หาก denominator ผิด:** ถ้า Emma ใช้ actual total growth 22% แทน 31% เป็นตัวหาร → implied growth priced (29.8%) ÷ 22% = **1.35x** — **เกิน threshold 1.2x = FAIL** (จาก preliminary PASS 0.96x) หาก Quinn ใช้ 22% แทน 31% → 12.73%/22% = 0.58x — ยังคง PASS แต่ margin แคบลงมาก (จาก 0.41x)

**ข้อสรุป:** นี่คือ data reconciliation gap ที่ต้องแก้ก่อนจะเชื่อ Growth MOS gate เต็มที่ — ไม่ใช่ hard error ที่พิสูจน์ได้จากข้อมูลที่มี (อาจอธิบายได้ด้วย organic-vs-total distinction) แต่ทั้ง Emma และ Quinn ไม่ได้ flag หรือ reconcile — **ต้องตรวจสอบเพิ่มจาก 10-Q MD&A** (out of scope งานนี้) ก่อน Growth MOS gate ถือว่าน่าเชื่อถือเต็มที่

## Bear's Own P-W EV

| Scenario | FY26E Revenue | EV/Rev Multiple (Bear's anchor) | EV | Equity Value (+net cash $0.19B) | Price/Share | Probability |

## Sensitivity Test (Fix #3 — Blended FV impact จาก challenged variable)

Challenged variable: Quinn's Base-case EV/Revenue multiple anchor (9.0x TTM-anchored → 7.5x forward-implied-anchored, -16.7%)

**Blended FV (ตาม CLAUDE.md weight Emma 40% / Quinn 30% / Bear 30%):**

- **Original:** FV = 0.40×$255 + 0.30×$318.07 + 0.30×$264.68 = $102.00 + $95.42 + $79.40 = **$276.82** → MOS = +2.55%
- **หาก Quinn's multiple anchor แก้เป็น 7.5x** (Quinn's P-W EV ใหม่ ≈ $294.30, คำนวณด้วย probability เดิม 30/45/25): Blended FV = 0.40×$255 + 0.30×$294.30 + 0.30×$264.68 = $102.00 + $88.29 + $79.40 = **$269.69** → MOS ≈ **-0.09%** (fairly valued พอดี)

**สรุป:** Blended FV เปลี่ยนจาก $269.69 (แทบไม่มี MOS เลย) ถึง $276.82 (MOS บาง +2.55%) ขึ้นกับว่าใช้ multiple anchor ไหน — **ไม่ว่าจะใช้วิธีไหน MOS อยู่ในช่วง knife-edge (-0.1% ถึง +2.6%) ไม่ใช่ comfortable margin** ตาม Growth-bucket standard ที่ควรมี MOS ชัดเจนกว่านี้ (reverse DCF/multiple percentile ผ่านได้ก็จริง แต่ upside-vs-downside ที่แท้จริงบางมาก)
