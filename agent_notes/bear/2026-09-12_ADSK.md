### 🚨 Challenge #3 — Methodology gap: Relative Valuation leg ของ Emma ไม่ sensitize ต่อ WACC/rate risk เหมือน DCF leg

**นี่คือจุดอ่อนเชิง methodology ที่สำคัญที่สุดที่ Bear เจอในรอบนี้:** Emma's Blended FV = DCF (50%) + Relative Valuation (50%) โดย Relative leg ใช้ static multiple (P/FCF 20x, Forward P/E 22x) **ไม่ปรับตาม WACC/beta ที่เปลี่ยนไปเลย** — แต่ในความเป็นจริง ถ้า risk-free rate/beta ที่กระทบ DCF discount rate สูงขึ้น มันควรกดดัน **forward multiple ทั้งตลาดด้วยเช่นกัน** (higher discount rate → lower justified P/E สำหรับทุก valuation approach ไม่ใช่แค่ DCF) การที่ Emma ปล่อยให้ Relative leg คงที่ที่ $275 ไม่ว่า WACC จะเท่าไหร่ ทำให้ Blended FV **understate ความเสี่ยงจริงจาก beta/rate shock** — เพราะ 50% ของ FV ไม่ได้ตอบสนองต่อความเสี่ยงที่กำลัง drive ทั้ง re-analysis รอบนี้เลย

### Sensitivity Test (Fix #3 — บังคับ)

ถ้า **beta** เปลี่ยนจาก 1.31 (Emma base) → **1.50 stress** (เหตุผล: regime-lag risk ตาม Challenge #2) **และ** ปรับ Relative Valuation multiples ให้สอดคล้องกัน (P/FCF 20x→17x, Forward P/E 22x→19x เพื่อสะท้อน rate-driven de-rating เดียวกับที่กระทบ DCF):
```
DCF ที่ WACC 11.76% ≈ $212
Relative ที่ multiple compressed = ($13.58×17 + $12.62×19) / 2 = ($230.86+$239.78)/2 = $235.32
Blended (stressed) = ($212 + $235.32) / 2 ≈ $224
```
เทียบกับ upside scenario ที่ beta ผ่อนคลายกลับไป 1.15 (rate cut trajectory confirm) + multiple ขยายเล็กน้อย (P/FCF 21x, Forward P/E 23x):
```
DCF ที่ WACC ~10.14% (beta 1.15) ≈ $258 (interpolate จาก Emma's table WACC 9.88%-10.38%)
Relative ที่ multiple expand = ($13.58×21 + $12.62×23) / 2 = ($285.18+$290.26)/2 = $287.72
Blended (bull) = ($258 + $287.72) / 2 ≈ $273
```

**→ ถ้า beta ± จาก 1.31 ไปที่ช่วง 1.15–1.50 (พร้อมปรับ relative multiples ให้ consistent) → Emma's Blended FV เปลี่ยนจาก $257 (point estimate) เป็นช่วง $224 – $273** — กว้างกว่าที่ Emma's sensitivity table (ซึ่ง sensitize เฉพาะ DCF leg) แสดงให้เห็น

**นัยสำคัญ:** ที่ downside ของช่วงนี้ ($224) เทียบราคาปัจจุบัน $212.40 → MOS เหลือแค่ **+5.5%** — **ไม่ผ่านเกณฑ์ 15% Value gate อีกต่อไป** ทั้งที่ยังไม่ได้เปลี่ยนสมมติฐาน revenue growth เลย (เปลี่ยนแค่ beta/multiple consistency) — แสดงว่า MOS +21.0% ของ Emma **เปราะบางกว่าที่ตัวเลขเดี่ยวแสดง** ขึ้นกับ assumption set ที่เลือกใช้

### 🚨 Challenge #4 — "Broad market-driven" explanation ของ -8.3% drop (Sept 3-4) ยังมีช่องโหว่ทางตรรกะ

Atlas สรุปว่า drop -8.3% เป็น "rate-driven amplification" ของ high-multiple/duration-sensitive stock — **แต่ Atlas เองก็ให้ข้อมูลที่ขัดแย้งกับข้อสรุปนี้บางส่วน:** Dow Jones ร่วงแค่ -0.51% วันเดียวกัน ขณะที่ ADSK ร่วง -8.3% = **amplification ratio ~16.3 เท่า** ตัวเลขนี้ **สูงเกินกว่าที่ beta 1.31 (แม้จะสูงกว่า market beta 1.0) จะอธิบายได้ทั้งหมด** — beta 1.31 ทำนายว่า ADSK ควรร่วงประมาณ 1.31 × 0.51% ≈ 0.67% ไม่ใช่ 8.3%

**Bear's take:** "rate-sensitivity amplification" เป็นคำอธิบายที่ **ฟังดูสมเหตุสมผล (narrative fallacy risk)** แต่ตัวเลขไม่ sup port ขนาดของการเคลื่อนไหวจริง มีความเป็นไปได้อื่นที่ยังไม่ถูกขุด:
- Options-related mechanical selling / gamma exposure ใกล้ month-end หรือ large strike level
- Index/ETF rebalancing flow (ADSK อยู่ใน software/tech ETFs หลายตัว)
- Large single institutional holder de-risking (13F/ownership data ไม่ได้ตรวจในเซสชันนี้ — data gap)
- Sector rotation ออกจาก design-software โดยเฉพาะ (ไม่ใช่ software ทั้งกลุ่ม) — ไม่ได้ confirm หรือ reject เพราะ WebSearch หมด budget

**สรุป: สาเหตุยัง unresolved จริง ไม่ใช่แค่ "ไม่พบ" แล้วปิดเคส** — ควร treat เป็น **known-unknown risk** ไม่ใช่ explained-away risk จนกว่าจะมีเซสชันที่มี WebSearch quota เหลือมาขุดเพิ่ม (13F filings, options flow data, ETF flow data)
