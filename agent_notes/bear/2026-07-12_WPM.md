**Bear P-W EV = 0.20×145 + 0.40×96 + 0.30×60 + 0.10×42**
**= 29.0 + 38.4 + 18.0 + 4.2 = $89.6 ≈ $90**

**MOS at $110.05 = (90 − 110.05)/110.05 = −18.2%**

- Bear P-W EV **$90** < Quinn $107.32 < ... (Emma base $100). ผม downside กว่าทั้งคู่ ~$10-17 เพราะ (a) anchoring correction บน base gold, (b) heavier tail, (c) haircut triple-stacked bull
