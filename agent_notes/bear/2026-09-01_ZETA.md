## 2. Challenge: Emma's Analysis

### 2.1 Valuation — Emma's internal 40% band เป็น red flag, ไม่ใช่ triangulation

Emma blends prob-weighted DCF **$16.50** (50%) กับ EV/Rev **$27.50** (50%) → point FV **$21.50**.

**Challenge:** การเฉลี่ย DCF $16.50 กับ EV/Rev $27.50 (gap 40% ภายในนักวิเคราะห์คนเดียว) แล้วเรียกมันว่า "triangulation" คือการ **manufacture precision จาก disagreement**. EV/Rev $27.50 อ้าง fair fwd multiple 3.75x — แต่ multiple นั้นเป็น **circular**: มันคือ "ZETA ควรเทรดที่ไหน" ซึ่งพึ่งสมมติฐานเดียวกับ DCF (growth durability + margin) ที่ DCF บอกว่าไม่พอ. ถ้า DCF ถูก (SBC เป็นต้นทุนจริง, owner FCF ~$30M) → fair EV/Rev ควรเป็น **2.5–3.0x** ไม่ใช่ 3.75x → EV/Rev method จะให้ **$19–23** ไม่ใช่ $27.50 → Emma point FV จะตกไป **~$18** ทันที.

**Fix #3 sensitivity:** ถ้า fair fwd EV/Rev = 2.75x (แทน 3.75x) → EV/Rev method $19.5 → Emma point FV = (16.50 + 19.5)/2 = **$18.0** (MOS −42%). ถ้า 3.0x → $21 → point FV $18.75.

**Verdict:** Emma FV $21.50 น่าจะ **สูงไป ~$3–4** จากการให้ credit EV/Rev method เต็มที่ทั้งที่ method นั้นไม่ได้จับ SBC wedge, gross-margin decline, cohort de-rating, litigation. Emma ยอมรับข้อนี้เองใน §2.6 ("methodology band กว้าง = สัญญาณ uncertainty").

## 5. Convergence Check + Shared Blind Spot [CFA L3: Behavioral — Groupthink]

**Conviction:** Emma 4.5 / Quinn 5.0 / Bear 7.0 — spread 2.5, ไม่มีใคร ≥ 8 → **Anti-Convergence Protocol ไม่ทริกเกอร์** (เงื่อนไข: ทั้ง 3 ≥ 8 และ gap < 1.5).
