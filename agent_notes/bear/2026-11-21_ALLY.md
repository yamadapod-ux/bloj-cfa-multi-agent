## Bear's Challenge: ALLY

### 🚨 จุดอ่อนใน Thesis ของ Emma [CFA L2: Equity Valuation — RI; CFA L3: Behavioral Finance]

1. **ROE path 10.5→11.5% ใน Y2–Y4 ชนกับ "ช่วงที่ loss ของ vintage ใหม่จะออกมา" พอดี.** Management ยอมรับเองว่า loan ที่ปล่อยช่วงปลาย 2025–ต้น 2026 มี early-stage DQ สูงขึ้น (American Banker; StockStory) — auto loan มักเห็น loss สูงสุดหลังปล่อย 12–24 เดือน → **ตรงกับปี 2027** ซึ่ง Emma ให้ ROE 11.0–11.5%. guide midpoint บังคับ Q4 retail NCO ~2.17% แล้ว (finsee) และ Q3 เป็นไตรมาสแรกที่ NCO ขึ้น YoY หลังลง 6 ไตรมาส. Emma ใช้ 3 แหล่ง (Q3 actual / consensus / mgmt "mid-teens") ซึ่ง**ล้วนเป็นมุมขาขึ้น** — Emma ยอมรับเองใน §7 flag (a) นี่คือ confirmation bias ที่ Emma ตรวจเจอแต่ไม่ได้ปรับ
   - *Sensitivity:* ถ้า ROE path −1.5pp (Emma 8b $43.77) → Blended FV **$44.06** · ถ้า no-recovery 7.8% (Emma 8c $33.52) → Blended **$39.96** (MOS 9.1% — ตก Value gate 15%)
2. **IRR 16.1% ใช้ payout 60% (ปันผล 29% + buyback 29%) แต่ fully-phased CET1 อยู่ 8.8% < เป้า 9%** และ buyback เร่งได้เมื่อถึง 9% เท่านั้น (finsee; 8.8% ยืนยันใน Ex. 99.2 ของ Emma เอง). ฉะนั้น distributions $15.74/หุ้นใน 5 ปี (43% ของราคา) เสี่ยงสูงเกิน. RI FV แทบไม่กระทบ (Emma #11: ±0.3%) **แต่ IRR ที่ใช้เทียบ S&P กระทบตรง** — Bear IRR ของตัวเองซึ่งลด payout ใน scenario เครดิต = **13.1%** (ไม่ใช่ 16.1%)
3. **"BV = 91% ของ FV" ทำให้ downside ดูจำกัด — แต่คุณภาพของ BV ยังไม่ได้ตรวจ.** (ก) lease residual: ขาดทุน $914/คันแล้ว (finsee) — Manheim ยังทรงตัว (+0.5% MoM) แต่ Cox ลด outlook ทั้งปีเหลือ ~+0.2% [Atlas §Sector] (ข) Corporate Finance reserve ลดจาก 1.83% เป็น 1.17% ทั้งที่ไม่เปิดเผย private-credit exposure (finsee, แหล่งเดียว) = reserve release ที่ช่วย EPS/BV (ค) fair value ของสินเชื่อรถดอกเบี้ยคงที่เทียบ book — **ไม่ได้ดึงมา ต้องตรวจสอบเพิ่ม** (10-K fair value note). BV₀ ไม่ใช่พื้นที่แข็งอย่างที่ RI framing ทำให้ดู
   - *Sensitivity:* BVPS₀ −5% ($41.08) โดยตัวอื่นคงเดิม → Emma FV ≈ $45.0, Bear FV ≈ $40.2 → Blended **≈ $43.4** (Bear linear approx: FV ≈ scale ตาม BV)
4. **Moat "cost advantage จากเงินฝาก" ที่ Emma ใช้กำลังอ่อนลงจริงในตัวเลข:** retail deposits ลง 2 ไตรมาสติด และ brokered deposits เพิ่มจาก $6.6B → **$13.9B** (9% ของ deposits; finsee) — ธนาคารที่มี deposit franchise แข็งไม่ต้องพึ่ง brokered มากขึ้นเท่าตัว. Emma ให้ Narrow− (ความเชื่อมั่นต่ำ) — Bear เห็นว่า **None/Narrow−** และ Filter E1 ไม่ผ่าน (ตรงกับ Emma)
5. **Customer/channel concentration = "N/A" ในรายงาน Emma แต่มีข้อมูลชี้ว่า Carvana-sourced loans ~12.1% ของ consumer auto loans** (finsee อ้าง 10-Q มิ.ย.; แหล่งเดียว — **ต้องตรวจสอบเพิ่ม**). ถ้าจริง = channel เดียวใกล้เกณฑ์ flag และ loan ที่ขายให้นักลงทุนภายนอกมี loss ~2 เท่าของที่ถือเอง (finsee) — เป็น selection-risk ที่ยังไม่มีใครโมเดล
6. **Corp & Other swing +$134M YoY / +$100M QoQ ยังอธิบายไม่ได้** — Bear ตรวจเพิ่ม: equity securities FV gain Q3 = แค่ $5M (ส่วนใหญ่อยู่ใน Insurance) [Ex. 99.1] → swing **ไม่ได้มาจาก equity mark** ส่วนใหญ่ → อาจเป็น hedge/treasury/funds-transfer-pricing ที่ซ้ำได้หรือไม่ได้ก็ได้. Emma ปรับ Q3 ROE เป็น ~9.8% อย่างถูกต้อง แต่ Y1 ROE 10.5% ยังสูงกว่าตัวเลขปรับแล้วนั้น
