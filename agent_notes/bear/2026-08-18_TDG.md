### 2. Quinn's Base case FV ($1,405) = Stifel's post-downgrade PT ($1,405) พอดี — anchoring risk

**Challenge:** Quinn's Base scenario (growth 13%, margin 52%, exit 17x) ให้ FV = **$1,405.00** — ตัวเลขนี้ตรงกับ **Stifel's price target หลัง downgrade (Aug 2026) พอดิบพอดี** [Investing.com, 2026-08](https://ca.investing.com/news/stock-market-news/stifel-cuts-transdigm-stock-rating-on-ma-and-regulatory-concerns-93CH-4776401) — Stifel downgrade เหตุผล: lower M&A, right-to-repair risk, aerospace demand moderation, rising rates — cut PT จาก $1,525 → $1,405

**คำถาม:** เป็นเรื่องบังเอิญที่ independent bottom-up model (growth×margin×multiple) มาจบที่ตัวเลขเดียวกับ sell-side PT เป๊ะ หรือ Quinn (แม้ไม่ตั้งใจ) calibrate exit multiple 17x เพื่อให้ output ออกมาใกล้เคียงกับตัวเลขที่คุ้นตาจาก Street? นี่คือ **Anchoring Bias** [CFA — Behavioral Finance, L3] แบบคลาสสิก — แม้ Quinn จะ derive จาก bottom-up ก็ตาม การเลือก exit multiple 17x (แค่ de-rate เล็กน้อยจาก current 18.77x) มีความเป็นไปได้สูงว่าถูกกำหนดแบบ "reverse-engineer จากราคาที่รู้สึกสมเหตุสมผลอยู่แล้ว" มากกว่าจะ derive จาก fundamental principle ล้วนๆ

**Sensitivity Test (บังคับ — Fix #3):** ถ้า exit multiple Base case เปลี่ยน ±2x จาก 17x (คือ 15x-19x, ยังคง de-rate จาก current 18.77x อยู่ ไม่ใช่ aggressive):
- Quinn's Base FV: **$905 (15x) – $1,905 (19x)** (ประมาณเชิงเส้นจาก Quinn's เอง 3 anchor points: 13x=$515, 17x=$1,405, 20x=$2,262, slope เฉลี่ย ≈$250/1x)
- Quinn's P-W EV ใหม่: **$1,146.75 (low) – $1,646.75 (high)**
- **Blended FV (40/30/30) เปลี่ยนเป็น $1,010.40 – $1,160.40 (MOS -17.9% ถึง -5.8%)**
- **ทั้ง range นี้ยัง FAIL threshold MOS≥15% ทุกจุด** — แสดงว่า BUY case ไม่ robust ต่อ reasonable exit-multiple assumption changes เลย

## Reconciliation: Emma vs Quinn Divergence

**Root cause ของ divergence (-34.5% MOS Emma vs +13.4% MOS Quinn):**
1. **Emma's absolute DCF ใช้ FCF discounting ล้วนๆ ที่ terminal growth ceiling 3% (house rule)** — ไม่มี mechanism ให้ M&A-funded growth (ซึ่งเป็น core growth engine ของ TDG มา 20+ ปี) เข้ามาเพิ่มมูลค่าเกิน organic taper — **conservative by construction**
2. **Quinn's P-W EV ฝัง exit-multiple assumption ที่ anchor ใกล้ current trading multiple (17-20x, current 18.77x)** — วิธีนี้ implicitly assume ว่า "ตลาดกำลัง price ถูกอยู่แล้วในระดับหนึ่ง" ซึ่งเป็น **circular reasoning แบบเดียวกับ ETN/VRT precedent** ที่ Emma เองก็ flag ไว้ล่วงหน้า
3. ทั้งสอง methodology ไม่ผิด — แต่ตอบคำถามต่างกัน: Emma ตอบ "มูลค่าที่แท้จริงจาก cash flow คือเท่าไหร่" Quinn ตอบ "ตลาดน่าจะ pay เท่าไหร่ถ้า multiple ไม่เปลี่ยนมากจากปัจจุบัน"
