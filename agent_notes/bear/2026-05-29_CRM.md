## 🚨 Core Challenges (คงเดิมจาก v1)

### Challenge 1: ROIC 6.3% < WACC 9.5% = EVA Negative
```
EVA = (6.3% - 9.5%) × ~$100B IC = -$3.2B/yr
```
M&A $50B+ (Slack $27.7B + Tableau $15.7B + MuleSoft $6.5B) ยัง not generating ROIC > WACC

**Bear แนวทาง:** ถ้า ROIC คงที่ 6.3% → DCF Terminal Value ควรใช้ lower multiple → FV ลดลง 20-30%

### Challenge 2: TGR 4% ยังเป็นประเด็น (แต่ Emma justify ได้)
Bear ยอมรับ CFA justification ของ Emma (US nominal GDP 4% = ceiling) แต่:
- ถ้า revenue growth ลดต่ำกว่า 5% → TGR 4% ≈ terminal growth ≈ growth premium ไม่มี → FV ลดลงมาก
- Bear case TGR 3% → Emma DCF FV ลดจาก $387 → ~$330 (-15%)

### Challenge 3: Microsoft Threat ยังเป็น Structural Risk
- M365 bundle = CRM อาจถูก commoditize ใน IT budget negotiations
- Copilot ฝัง workflow = Agentforce compete ใน embedded AI ที่ถูกกว่า
- ถ้า Microsoft ขโมย 5% share ใน 3 ปี → Revenue impact -$2B → FV ลดลง 15-20%

### Challenge 4: FCF Yield Signal Warning
FCF yield สูงอาจเป็น Value Trap signal:
- ราคา -43% จาก ATH → FCF yield สูง = ตลาดรู้บางอย่างที่ model ไม่ capture
- ถ้า FCF ลดลง 15% (competition pressure) → FCF yield ที่ $181 = 7.1% → Fair Value ลดลง
