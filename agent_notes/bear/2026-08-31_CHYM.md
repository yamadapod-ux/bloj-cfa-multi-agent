## 2. Challenge Emma [CFA L2: Equity Valuation — DCF Assumption Review]

### 2.1 DCF Assumptions — จุดที่ Emma ยัง generous เกินไป

**(A) Terminal GAAP EBIT margin (Base 20%) — ยังสูงไป ถ้า moat = None**
Emma ให้ base terminal GAAP EBIT margin 20% (≈ adj EBITDA ~27%). แต่ถ้ายอมรับว่า CHYM **ไม่มี pricing power** (Q2'26: "traded 1bp of take-rate for 5pts of volume" — Emma เองยกเป็นหลักฐาน anti-moat) + partner banks กิน revenue-share + ARPU ceiling → competitive equilibrium margin ควรต่ำกว่า. Interchange-only neobank ที่ไม่มี charter ไม่ควร assume margin เท่า SoFi (17.3%) ด้วยซ้ำ เพราะ SoFi มี NIM. Peer ที่ margin สูง (NU 52%, DAVE 36%) มี product mix / charter / geography ที่ต่างสิ้นเชิง.

> **Sensitivity Test [Fix #3]:** ถ้า terminal GAAP EBIT margin = **16%** แทน 20% (competitive-erosion case) → Emma DCF base ≈ **$18** (จาก $21) → Emma point FV ≈ **$20** (จาก $22.50) → **Blended FV เปลี่ยนจาก ~$22.3 เป็น ~$21.3** (MOS −32.8% → −35.8%). ตรงข้าม ถ้า NU-style 30% → Emma base ≈ $27, Blended ≈ $24.5 (MOS −26%).

**(B) Bull scenario probability 20% — สูงไป, ควร 15%**
Bull ของ Emma ($35, +5%) ต้องการ **3 เงื่อนไขพร้อมกัน**: (1) growth re-accelerate สู่ 27% (2) terminal margin 25% (3) multiple ไม่ de-rate ในภาวะ Fed-hawkish. CHYM ปัจจุบัน**อ่อนที่สุดในกลุ่ม peer ทั้ง growth และ margin** — การ bet ว่าจะพลิกเป็น top-quartile ทั้งสองด้าน + multiple hold = triple conjunction. Quinn's matrix ยืนยัน: 6/25 cells (24%) เท่านั้นที่ justify $33.20. → Bull ควร **15%** ไม่ใช่ 20%.

> **Sensitivity Test [Fix #3]:** ถ้า Bull 20%→15% (โยกไป Bear +3%, Severe +2%) → Emma P-W EV $20.20 → **~$19.2**; Quinn P-W EV $24.47 → **~$22.9** → **Blended FV ~$22.3 → ~$21.3**.

**(C) Share count divisor 400M — อาจ optimistic**
Emma ใช้ 400M (net dilution ~1.5%/yr − assumed buyback). แต่ SBC run-rate ~$260M/yr (§5, 10-Q 6mo $130.1M) บนหุ้น $33 = ~7.9M share/yr gross ≈ 2.1%/yr **ก่อน** buyback. Buyback ยังไม่ประกาศเป็น program ทางการ. Conservative divisor = ~410–420M ภายในปี 10 → FV/share ต่ำลงอีก ~3–5%.

**(D) WACC 13.0% base — beta 1.70 อาจต่ำไป (ดู §3.1)** — ถ้าใช้ beta 1.9 → WACC ~14.1% → Emma base $21 → ~$18.

### 2.2 Moat Rating — NARROW สูงไป, Bear เชื่อ **NONE (weak-Narrow at best)**

| ประเด็น | Emma (NARROW, durability 7–10 ปี) | Bear challenge |

## 3. Challenge Quinn [CFA L2: Quantitative Methods — Model Input Review]

### 3.1 Beta proxy 1.70 — **ต่ำไปสำหรับ micro-float 50x P/E**

Quinn เลือก 1.70 ทั้งที่ peer average ของตัวเอง = **1.84 (incl NU)** หรือ **2.13 (ex-NU)**. เหตุผลที่ Quinn discount ลงมา (fee-based rate-insensitive core, net cash) มีน้ำหนัก **แต่ถูก offset จนหมด**ด้วย:
- Multiple-compression sensitivity "↑↑" (Quinn ยอมรับเอง) — 50x fwd P/E บน rate-shock
- Micro-float post-IPO + VC overhang (DST/General Atlantic/Menlo ยังถือ) + low institutional depth → ↑
- **Consumer-credit-sensitive demographic ตอนนี้มี credit risk บน balance sheet จริง** (Instant Loans unsecured, §5) — labor-market beta สูงขึ้นกว่าที่ Quinn model
- **Observed drawdown −53% ถึง −65% ใน 14 เดือนแรก** — vol realized บอกว่า forward beta ≥ 2

**Bear เชื่อ forward beta 1.9–2.1 (point 2.0)** — anchor ที่ ex-NU peer avg 2.13, discount เล็กน้อยจาก net cash.

> **Sensitivity Test [Fix #3]:** beta 1.70 → 2.00 → WACC 13.0% → **~14.4%**. จาก Quinn WACC mini-sensitivity: FV @ 14.5% = $22.24. → **Quinn base FV $26.00 → ~$22.5**; Quinn P-W EV $24.47 → **~$21.5**. → **Blended FV ~$22.3 → ~$20.9** (MOS −32.8% → −37%).
