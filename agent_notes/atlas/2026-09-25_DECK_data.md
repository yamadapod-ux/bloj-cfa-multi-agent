## (f) WACC Build-Up (shown in full, DECK-specific)

**Step 1 — Cost of Equity (CAPM):**
```
Re = Rf + β × ERP
Rf  = 5.17%   (10Y UST, CNBC, cited above)
β   = 1.15    (5Y monthly, Yahoo Finance / stockanalysis.com, cited above)
ERP = 4.14%   (Damodaran implied ERP, Sept 1 2026, trailing-12mo adjusted-payout method —
               pages.stern.nyu.edu/~adamodar/)

Re = 5.17% + 1.15 × 4.14%
   = 5.17% + 4.76%
   = 9.93%  ≈ 9.9%
```

**Step 2 — Cost of Debt:**
- DECK total debt: **$472.33M** (stockanalysis.com/stocks/deck/financials/balance-sheet/, TTM) — predominantly operating/finance lease liabilities, not traded corporate bonds (10-Q shows "Long-term operating lease liabilities $398.976M" as the dominant long-term liability line — ir.deckers.com/sec-filings/.../deck-20260630.htm).
- **DECK is a net-cash company**: Net Debt/Equity ratio = **-0.49** (negative — cash exceeds debt) per stockanalysis.com/stocks/deck/financials/ratios/. No public bond rating readily located (company does not appear to have rated public debt outstanding at this size).
- Given the immaterial/non-public-market debt load, cost of debt is proxied as Rf + a conservative investment-grade spread (~100bps) rather than pulled from a nonexistent bond quote:
```
Rd (pre-tax) ≈ Rf + 1.00% spread = 5.17% + 1.00% = 6.17%
Tax rate = 23% (per FY2027 guidance, cited above)
Rd (after-tax) = 6.17% × (1 - 0.23) = 6.17% × 0.77 = 4.75%
```

**Step 3 — Capital Structure Weights (market values):**
```
E (market cap) ≈ $11.0B   (cited above)
D (total debt) ≈ $0.472B  (cited above)
V = D + E ≈ $11.47B

E/V = 11.0 / 11.47 = 95.9%
D/V = 0.472 / 11.47 = 4.1%
```

**Step 4 — WACC:**
```
WACC = (E/V × Re) + (D/V × Rd_after-tax)
     = (0.959 × 9.93%) + (0.041 × 4.75%)
     = 9.52% + 0.19%
     = 9.72%  ≈ 9.7%
```

**Atlas WACC estimate for DECK: ~9.7%** (within the 7-13% sanity band). Note the WACC is dominated almost entirely by cost of equity since DECK carries minimal, non-traded debt relative to its market cap — Emma should treat this as effectively an all-equity discount rate.
