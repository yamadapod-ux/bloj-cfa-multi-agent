## 1. 🏢 Business Deep Dive

### How Does Mastercard Make Money?

1. **Service Fees (~33% of net revenue)**: ค่าธรรมเนียมที่เก็บจาก issuers และ acquirers เป็น % ของ GDV (Gross Dollar Volume) ที่ผ่านระบบ — transaction-based, ไม่ขึ้นกับ credit risk
2. **Assessment/Domestic Assessment Fees (~39%)**: ค่าธรรมเนียมที่เก็บจาก issuers/acquirers ตามจำนวน switched transactions และ cross-border volume
3. **Cross-Border Volume Fees (~20%)**: ค่าธรรมเนียม premium สำหรับ international transactions — สูงกว่า domestic อย่างมีนัยสำคัญ = margin driver
4. **Processing Fees (~8%)**: ค่าธรรมเนียม per-transaction สำหรับ transaction processing ผ่าน Mastercard network
5. **Other Revenue (Value-Added Services ~15-20%)**: Cyber & intelligence solutions, data analytics, consulting, loyalty solutions — growing higher-margin segment

**Key Insight:** MA ไม่รับ credit risk — เป็น pure toll-road operator ที่ได้ค่าผ่านทางเป็น % ของ transaction value → asset-light, ultra-high FCF model

## 2. 🏰 Economic Moat Analysis [CFA L2: Economic Moat + Competitive Advantage]

### Moat Type: WIDE

**5 Moat Sources:**

1. **Network Effects (Most Important)** — MA network value ∝ N² (Metcalfe's Law): 3.3B cards, 90M+ merchants, 210+ countries. เพิ่ม 1 merchant = ทำให้ทุก cardholder มีประโยชน์มากขึ้น; เพิ่ม 1 cardholder = ทำให้ทุก merchant มีประโยชน์มากขึ้น. **Network effect = widest moat ใน portfolio นี้** (กว้างกว่า CUDA, กว้างกว่า FDA CSV)

2. **Intangible Assets** — Mastercard brand = ยอมรับได้ทุกที่ในโลก; PCI DSS security standard knowledge; tokenization IP; fraud detection algorithms (Mastercard AI) = regulatory moat

3. **Switching Costs** — Banks ที่ออก Mastercard cards ต้องเปลี่ยน IT system, reissue cards (~$4-6/card × billions), re-train staff, re-negotiate merchant contracts = switching cost สูงมาก; แม้แต่ Apple Pay/Google Pay ใช้ Mastercard network = nested switching cost

4. **Scale Economies** — Fixed cost of network infrastructure / number of transactions = เมื่อ volume เพิ่ม margin เพิ่มแบบ operating leverage; MA EBITDA margin ~55-60% = evidence of extreme operating leverage

5. **Cost Advantages** — Transaction processing cost per unit ต่ำกว่า competitors เพราะ scale; fraud loss ต่ำกว่า เพราะ AI/ML trained on larger dataset

**Moat Durability:** HIGH (10+ years) — network effect moat ยิ่งใหญ่ขึ้นเมื่อ network เติบโต; ไม่มี single competitor ที่จะทำลาย overnight
