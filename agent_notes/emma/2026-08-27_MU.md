## Methodology

MU เป็น commodity memory-chip manufacturer (DRAM/NAND/HBM) ที่กำลังอยู่ในช่วง **cycle peak ที่รุนแรงที่สุดในประวัติศาสตร์บริษัท** (TTM Revenue +166.98% YoY, Op Margin 65.67%, ROE ~66.64%, ROIC ~67.64% — ตัวเลขทั้งหมดนี้คือ cyclical-peak, ไม่ใช่ sustainable steady-state) Atlas สั่งชัดเจนห้าม extrapolate TTM growth เป็น perpetuity — ดังนั้น methodology ที่เลือกใช้:

1. **DCF (FCFF, Operating-Income/NOPAT-based)** — multi-stage model ที่ built-in cyclical correction (อิง FY2023 -49% เป็น historical precedent) แทนที่จะ extrapolate TTM ตรงๆ — ใช้เป็น **secondary/context valuation** (per house rule, Growth bucket ใช้ EV/Revenue + Reverse DCF เป็น primary)
2. **Growth MOS — 2 วิธีบังคับ (Reverse DCF + Multiple Percentile)** — นี่คือ **primary gate** สำหรับ Growth bucket BUY decision
3. **Peer Comparison** — เทียบ SKHY, SNDK, STX, WDC ตาม Atlas peer set
4. **ESG Risk Scorecard**
5. **SaaS Unit Economics: N/A — not subscription-based** (semiconductor manufacturer, one-time product sale, ไม่ใช่ recurring-revenue business)

### DCF Cash-Flow Consistency Statement [ตาม CLAUDE.md DCF Cash Flow Consistency Rule]
SBC ของ MU = $972M FY2025 / Revenue FY2025 $37.38B = **2.6% ของ Revenue** [Source: businessquant.com/metrics/mu/share-based-compensation-annual, WebSearch 2026-08-27] — **ต่ำกว่าเกณฑ์ 10% ที่ trigger กฎนี้อย่างเข้มงวด** ดังนั้น SBC ไม่ใช่ตัวบิดเบือนหลักสำหรับ MU (ต่างจาก SaaS names อย่าง VEEV) — **ตัวบิดเบือนหลักของ MU คือ Capex timing + Net Working Capital swing จากการเติบโตของรายได้ที่รุนแรงมาก (revenue เกือบ 3 เท่าใน 1 ปี)** ไม่ใช่ SBC add-back

**Cash-flow basis ที่ใช้:** Operating-Income/NOPAT-based FCFF เสมอ (ตาม default ของ Emma) — **ไม่ใช้** reported "Free Cash Flow" TTM $26.17B เป็นจุดเริ่มของ DCF projection โดยตรง เพราะตัวเลขนี้สะท้อน capex ที่กำลังพุ่งขึ้นมาก (fab expansion สำหรับ HBM capacity) และ NWC drag จาก revenue ramp ที่ผิดปกติ — ใช้เป็นแค่ cross-check reference point เท่านั้น

### 4. Reverse DCF — Implied Growth Rate [Growth MOS Test 1]

ใช้ single-stage Gordon Growth บน TTM NOPAT (peak) เพื่อหา implied perpetual growth ที่ตลาด price ไว้ ณ ราคาปัจจุบัน:

- EV ปัจจุบัน = Market Cap $1,037,000M + Debt $6,380M − Cash $24,990M = **$1,018,390M**
- NOPAT TTM = EBIT $59,280M × (1−0.15) = **$50,388M**
- Solve: EV = NOPAT×(1+g)/(WACC−g)
- $1,018,390 = $50,388×(1+g)/(0.1563−g)
- **g (implied perpetual growth) ≈ 10.18%**

**เทียบกับ consensus:** 5-Year EPS growth consensus (median) = **-10.4%** (คาดการณ์ EPS หดตัวต่อเนื่อง ไม่ใช่โต) [Source: finbox.com/NASDAQGS:MU/explorer/eps_proj_growth_median/, WebSearch 2026-08-27]

**ผลตรวจ Growth MOS Test 1 (Reverse DCF):**
implied growth (+10.18% ต่อปี, perpetuity) ต้อง ≤ 1.2× consensus growth — แต่ consensus growth เป็น **ลบ** (-10.4%) ดังนั้น implied growth ที่เป็นบวกใดๆ ก็ **เกินเกณฑ์ทันที** → **FAIL ชัดเจน** ตลาดกำลัง price ว่า peak NOPAT ของ TTM (คือ cycle-top ที่สุดในประวัติศาสตร์บริษัท) จะไม่เพียงแค่ sustain แต่จะโตต่อ >10%/ปี ตลอดไป — ขณะที่ Street เองคาดว่า EPS จะ**หดตัว**ในอีก 5 ปีข้างหน้า (สอดคล้องกับ historical cyclicality — ไม่มีบริษัท memory ใดเคยรักษา margin ระดับ peak ได้ต่อเนื่องยาวนาน)

## Business Deep Dive (สำหรับ Charlie ใช้ประกอบ Report)

### How does Micron make money?
> - ผลิตและขายชิปหน่วยความจำ **DRAM** (memory ที่ทำงานร่วมกับ CPU/GPU ตลอดเวลา — ใช้ใน PC, server, smartphone)
> - ผลิตและขาย **NAND flash** (memory เก็บข้อมูลถาวร — ใช้ใน SSD, storage devices)
> - ผลิต **HBM (High Bandwidth Memory)** — memory พิเศษความเร็วสูงที่ขายให้ผู้ผลิตชิป AI (Nvidia, AMD) ใช้คู่กับ AI accelerator — ปัจจุบันเป็น segment ที่ margin สูงสุดและ demand ล้นตลาด ("sold out" สำหรับปีนี้)
> - ลูกค้าหลักคือ hyperscaler/cloud data center, ผู้ผลิต PC/สมาร์ทโฟน, ผู้ผลิตรถยนต์/อุตสาหกรรม
> - รายได้ผันผวนตามราคาตลาด memory ซึ่งเป็นสินค้าโภคภัณฑ์ (commodity) — กำไรขึ้นอยู่กับ capacity utilization และต้นทุนการผลิตต่อหน่วยเทียบคู่แข่ง

## 🔄 DCF Revision — Terminal Growth Rate Fix (Morgan QA Feedback, 2026-08-27)

**สาเหตุ:** Morgan QA FAIL — Terminal Growth Rate (g) เกินเพดาน sanity-check (1%-3%) ตาม Morgan QA Protocol: Base Case ใช้ g=4%, Bull Case ใช้ g=6% ทั้งคู่เกินเพดาน แก้เป็น **g=3% (max ของเพดาน)** ทั้งสอง scenario — FCFF Year 1-5 ของทั้งสอง scenario **ไม่เปลี่ยน** (explicit forecast ไม่เกี่ยวข้องกับ terminal growth assumption) เปลี่ยนเฉพาะ Terminal Year (Y6) และทุกอย่างที่ตามมา (TV, PV TV, EV, Equity Value, Fair Value, MOS)

### A. Base Case — Terminal Year Recalculation (g: 4% → 3%)

Revenue Y5 (FY2031E) = $82.97B (unchanged) → **Revenue Y6 = $82.97B × 1.03 = $85.46B**

คงสัดส่วนเดิมทุกตัว (สัดส่วนเดียวกับที่ใช้ตอน g=4%): Op Margin 35%, D&A = 10% of revenue, Capex ratio = 27.00% of revenue (23.30/86.29 ในเวอร์ชันเดิม), ΔNWC ratio = -0.9966% of revenue (-0.86/86.29 ในเวอร์ชันเดิม)

| Item | Calculation | Value |
|------|-------------|-------|
| Revenue Y6 | $82.97B × 1.03 | **$85.46B** |
| NOPAT | $85.46B × 35% × (1-15%) | **$25.42B** |
| D&A | $85.46B × 10% | **$8.55B** |
| Capex | $85.46B × 27.00% | **$23.07B** |
| ΔNWC | $85.46B × (-0.9966%) | **-$0.85B** |
| **FCFF Terminal (Y6, g=3%)** | 25.42+8.55-23.07-0.85 | **$10.05B** |

**Terminal Value** = $10.05B / (0.1563 − 0.03) = $10.05B / 0.1263 = **$79.57B**

**PV of Terminal Value** = $79.57B × 0.4842 (Y5 discount factor, unchanged) = **$38.53B**

**PV FCFF Y1-5** = $36.96B *(unchanged — explicit forecast period ไม่เกี่ยวกับ terminal g assumption)*

**Enterprise Value** = $36.96B + $38.53B = **$75.49B**

**Equity Value** = $75.49B + Net Cash $18.61B = **$94.10B**

**DCF Fair Value (Base Case, g=3%) = $94.10B ÷ 1,129M shares = $83.35/share**

**MOS (Base, g=3%) = ($83.35 − $918.31)/$918.31 = -90.9%**

*(เทียบเดิม g=4%: FV $86.61, MOS -90.6% — การลด g ลง 1pp ทำให้ FV ลดลง ~$3.26 (-3.8%) และ MOS แย่ลงอีก ~0.3pp — ทิศทาง conclusion ไม่เปลี่ยนแปลง)*

### B. Bull Case — Terminal Year Recalculation (g: 6% → 3%)

**หมายเหตุ methodology:** ไฟล์เดิม (บรรทัด 80-86) แสดงเฉพาะสรุป FCFF Year 1-5 และผลลัพธ์ TV/EV ของ Bull Case โดยไม่ได้ tabulate breakdown เต็มรูปแบบเหมือน Base Case ดังนั้นในการ revise ครั้งนี้ ต้อง back-solve Revenue path ของ Bull Case จาก growth rate ที่ระบุไว้ (+8%/-15%/+5%/+10%/+8% บน TTM base เดียวกับ Base Case $90.27B) เพื่อหา Revenue Y5 แล้วจึงคำนวณ Terminal Y6 ใหม่ — ใช้ capex ratio (27.00%) และ ΔNWC ratio (-0.9966%) **ชุดเดียวกับ Base Case terminal** เพื่อความสอดคล้องของ methodology (เพราะไม่มีตัวเลข breakdown ต้นฉบับของ Bull terminal ให้ reuse ตรงๆ)

*(หมายเหตุ: sensitivity test นี้รันก่อนการแก้ terminal g — หลังแก้เป็น g=3% ตัวเลข base FV ขยับลงเล็กน้อยจาก $86.61→$83.35 แต่ทิศทาง conclusion ของ sensitivity test ไม่เปลี่ยน เพราะการเปลี่ยน beta assumption และการเปลี่ยน terminal g เป็น independent adjustments ที่ทั้งคู่ทำให้ MOS ติดลบหนักเหมือนเดิม)*
