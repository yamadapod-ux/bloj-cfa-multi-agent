## 3. วิธี Flex ระดับ Segment (Multi-Segment/SOTP Consistency Rule — บังคับ ตาม Opus addendum ข้อ 3)

- **TGR:** ปรับค่าเดียวกันทุก segment (AWS และ Retail ใช้ TGR เดียวกันในสูตร Gordon Growth ของ terminal value แต่ละ segment ก่อนรวม — ไม่ใช่ปรับที่ consolidated level เพียวๆ)
- **WACC:** ปรับค่าเดียวกันทุก segment (ใช้ discount rate เดียวที่ segment-level DCF ทั้ง AWS และ Retail แล้วรวม PV — สอดคล้องกับที่ v3.2 ใช้ WACC เดียวกันทั้งบริษัทอยู่แล้ว ไม่ใช่ WACC แยกตาม segment risk)
- **Terminal EBIT margin:** เลื่อน margin **ทุก segment ขึ้นเท่ากันเป็น pp** (ไม่ scale เป็น % หรือปรับ segment เดียว) — AWS 42.0%→51.6% (+9.58pp) และ Retail 8.0%→17.6% (+9.58pp) ในปีเดียวกัน (2035) จากนั้น margin ปีก่อนหน้าของแต่ละ segment ก็เลื่อนตาม pp เดียวกันตาม linear path เดิม — ให้ consolidated terminal margin เป็น**ผลลัพธ์**จาก mix ของทั้งสอง segment ใหม่ (ไม่ตั้ง consolidated margin ตรงๆ, สอดคล้อง F1 rule)
- **Revenue CAGR (10yr explicit):** scale **อัตราการเติบโต YoY ของทุกปีทุก segment ด้วยตัวคูณเดียวกัน** (growth_scale = 1.529×) — ไม่ใช่ scale เฉพาะปีใดปีหนึ่งหรือ segment ใดเดียว — AWS และ Retail ทั้งคู่ถูก scale ด้วยตัวคูณเดียวกันทุกปี (2026-2035) แล้วค่อยรวม revenue เป็น consolidated (bottom-up, สอดคล้อง F1)

ทุกกรณี **ไม่แก้ capex/D&A-as-%-of-revenue schedule** (คงเดิมตาม v3.2) — เปลี่ยนแค่ 1 ตัวแปรต่อครั้งตามกฎ "แก้ทีละตัวแปร ตัวอื่นคงเดิม"

## 4. ผลกระทบต่อ Blended FV (บังคับ — Opus addendum ข้อ 2, ANTI-GOAL-SEEKING)

เพราะทั้ง 4 ตัวแปรถูก solve ให้ **Emma FV = ราคาตลาดเป๊ะ ($259.92)** โดยนิยาม (gap-closing solution คือค่าที่ทำให้ FV เท่าราคา) — ผลต่อ Blended FV จึง**เหมือนกันทั้ง 4 กรณี**:

```
Blended FV = 0.4 × Emma FV + 0.3 × Quinn P-W EV + 0.3 × Bear FV
           = 0.4 × $259.92 + 0.3 × $131.69 + 0.3 × $89.13   (Quinn/Bear = v3.2 เดิม, ไม่เปลี่ยน)
           = $103.97 + $39.51 + $26.74
           = $170.21

MOS = ($170.21 − $259.92) / $259.92 = −34.5%
```

**แม้ Emma DCF FV ปิด gap ได้สมบูรณ์ (เท่าราคาตลาดเป๊ะ) Blended FV ยังต่ำกว่าราคาตลาด 34.5%** เพราะ Quinn P-W EV ($131.69) และ Bear FV ($89.13) ยังเป็นค่าเดิมของ v3.2 ไม่เปลี่ยน (คนละ methodology คนละ scenario ของตัวเอง ไม่ใช่ copy จาก Emma) — **ค่า Emma FV ที่จะทำให้ Blended FV = ราคาตลาดเป๊ะคือ:**

```
Emma FV ต้องการ = (Price − 0.3×Quinn − 0.3×Bear) / 0.4
               = ($259.92 − 0.3×$131.69 − 0.3×$89.13) / 0.4
               = ($259.92 − $39.51 − $26.74) / 0.4
               = $193.67 / 0.4
               = $484.19/share
```

Emma FV $484.19 สูงกว่าราคาตลาดปัจจุบันเองถึง 86% — ไม่มีตัวแปรใดใน §2 (ที่อยู่ในช่วงสมเหตุผล) พาไปถึงระดับนี้ได้แม้ตัวที่ใกล้ที่สุด (TGR 6.69% ก็พาไป Emma FV แค่ $259.92 เท่านั้น ยังห่าง $484 มาก)

**"เปราะ" ใน Emma DCF FV (สมมติว่าตัวแปรใดปิด gap ได้) ไม่ได้แปลว่า verdict พลิกโดยอัตโนมัติ** — ต้องดู Blended เสมอ

## 5. ความเชื่อมโยงกับ Open Item C2 (ระบุเพิ่ม — ไม่ resolve)

C2 (`reports/AMZN_2026-10-07_v3.md` §C2) ตั้งคำถามว่า retail DCF อาจ **understate** เพราะ Ads (margin สูง, โตเร็ว) ฝังอยู่ใน NA/Intl แต่ terminal growth ของ retail segment ใช้ 4% ทั้งก้อนแบบ undifferentiated — **ผลการทดสอบรอบนี้เกี่ยวข้องกับ C2 ดังนี้:**
- ตัวแปร **Revenue CAGR** และ **Terminal margin** ทั้งสองเป็นตัวแปรที่ C2 พูดถึงโดยตรง (ถ้า Ads จริงๆ โต/margin สูงกว่าที่ retail-blended สะท้อน → ทั้ง revenue growth และ margin ของ retail segment ควร**สูงกว่า**ที่ v3.2 ตั้งไว้) — ถ้า C2 ถูก resolve ในทางที่ retail understate, ค่า**เริ่มต้น** (base) ของทั้งสองตัวแปรนี้อาจขยับขึ้นเล็กน้อยแบบมี source (ไม่ใช่การ "ปิด gap เทียม")
- **แต่ขนาดของการขยับที่ C2 implies (Ads คาดว่า ~$82B revenue, margin ~40%, เทียบ retail รวม >$650B revenue margin ~6-8%) เล็กกว่าขนาดที่จำเป็นในการปิด gap มาก** (margin ต้องขยับ +9.58pp ทั้ง AWS+Retail เพื่อปิด gap เทียบกับ Ads carve-out effect ที่ Emma เคยคำนวณไว้ว่าทำให้ SOTP ต่างกันแค่ ~5-12% ไม่ใช่หลาย 100%) — **C2 ไม่สามารถอธิบาย gap ทั้งหมดได้แม้ resolve ไปทางที่ retail understate จริง** เป็นเพียงปัจจัยรองที่อาจเลื่อน base-case เล็กน้อย ไม่ใช่ตัวปิด Market-Implied gap ($259.92 vs $148.53)
