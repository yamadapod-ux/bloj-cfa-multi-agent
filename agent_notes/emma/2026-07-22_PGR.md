## 4. Valuation [CFA L2: Residual Income / Justified P/B-ROE]

### Key Inputs
- BVPS₀ = Shareholders Equity / Shares = $34.33B / 581.40M = **$59.05**
- Current P/B = $205.90 / $59.05 = **3.49x**
- Cost of Equity (r) = **9.0%** (floor — CAPM literal ให้แค่ ~5.7% ที่ Beta 0.25, ต่ำเกินจริงเพราะไม่ capture underwriting/severe-weather tail risk — ใช้ floor เดียวกับ ACGL 9.0% + Fed hawkish pivot risk เพิ่ม CoE)

### Method 1 — Two-Stage Residual Income (PRIMARY)
Stage 1 (Yr 1-3): ROE fade **32% → 29% → 26%** (สะท้อนการ normalize จาก ROE TTM 34.94% ที่เป็น elevated level — combined ratio กำลังแย่ลง YoY 86.2→87.1 = สัญญาณ margin เริ่ม normalize)
Retention ~55% (ROE × retention = BVPS growth rate)
Terminal: ROE 20%, g=5%, r=9%
**RI Method FV ≈ $255**

### Method 2 — Justified P/B-ROE (single-stage, normalized ROE)
Justified P/B = (ROE − g)/(r − g) = (20% − 5%)/(9% − 5%) = 3.75x
FV = 3.75 × $59.05 = **$221**

### Method 3 — BVPS Compounding Cross-check
BVPS grows ~11%/yr for 3yr → BVPS₃ ≈ $80.78; exit P/B 3.0x → exit value $242.34; discount back 3yr @ 9% → **FV ≈ $187**

= 0.50×$255 + 0.20×$221 + 0.30×$187 = $127.5 + $44.2 + $56.1 = **$227.8 ≈ $228**
