## 🎓 บทเรียนหลัก (lessons จาก session นี้)

### Lesson A — "Stop breach + Bear Flip ≠ Thesis Invalidation" (precedent ใหม่)
สถานการณ์ ACN: ราคาหลุด stop ($128 < $148, -28%) **และ** Bear Flip #1 (rev growth <5% via guide cut) firing — แต่ formal Thesis Invalidation (exit ทันที) ยังไม่ครบ (ต้อง 3 consecutive Q + rev <4% / >10% AI layoff / client exit).

**Decision framework ที่ใช้ (เก็บเป็น precedent):**
| สัญญาณ | กฎ | Action |
|--------|-----|--------|
| ราคาตกเฉยๆ (no fundamental change) | stop breach + thesis intact | flag, ไม่ขาย (review) |
| **Bear Flip firing** | report ระบุ "REDUCE/SELL" | **REDUCE = TRIM** |
| Thesis Invalidation ครบ | EXIT immediately | full SELL |

→ ACN = กลางๆ: Bear Flip firing (REDUCE) แต่ไม่ถึง Invalidation (full exit) → **TRIM 50%** เป็นคำตอบที่ rule-consistent ที่สุด. Full exit จะ "ข้ามหน้า" Invalidation criteria ของเราเอง; hold เฉยๆ จะละเลย stop ที่ตั้งไว้.
**ยังต้องพิสูจน์:** trim ถูกหรือเปล่า → Q4 bookings + ราคา 30 วันจะบอก. ถ้า ACN bounce = trim เร็วไป; ถ้าลงต่อ = trim ถูก + ยืนยัน exit ที่เหลือ.
