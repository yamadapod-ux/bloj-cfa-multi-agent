## Learning Points to Add to learning-log.md

### New Frameworks This Session

1. **"TRIM/HOLD" as Distinct Rating** — When portfolio has position that: (a) thesis still valid, (b) MOS negative, (c) large unrealized gain → TRIM = partial profit-take, HOLD remaining for optionality. Different from HOLD/WAIT (=no position yet).

2. **Re-Analysis After +100% Price Move = Rule** — When a BUY position gains >100%, mandatory re-analysis triggered. Even if thesis validated, MOS may now be negative. MRVL confirms this rule: thesis 100% validated, price 137% up, MOS now -30%.

3. **Sensitivity Matrix "Coverage Ratio"** — Quinn innovation: count cells where price is at/below FV. < 30% = "upper quartile" price = expensive. MRVL at 24% = expensive. This % should become standard metric in every analysis.

4. **NVDA as Competitive Threat to Custom Silicon** — Bear identified new dimension: NVDA inference ASIC strategy directly competes with hyperscaler custom silicon thesis. First time this risk explicitly modeled. Should be in every MRVL/AVGO/ASIC analysis going forward.

5. **Semiconductor Ceiling Management via Profit-Taking** — MRVL trim reduces semi exposure 19%→17.5%. This is natural portfolio management: win/trim creates room for new positions without forced selling.
