## 4. Kelly Criterion [CFA L3: Portfolio Construction — Kelly Criterion]

### Kelly Calculation
- Expected return (base case): +3.3% = ($500 - $484) / $484
- Expected return (weighted P-W EV): ($480 - $484) / $484 = -0.8%
- Standard deviation: ~18-22% (payment network historical vol)

**Kelly = (μ - r_f) / σ²**
= (P-W EV expected return ~+0.4%) / (20%)² = ~1%

**Quarter-Kelly = ~0.25%** → effectively 0 = neutral signal

**Forward Sharpe Ratio:**
= (P-W Expected Return 0.4% - Risk-free 4.4%) / σ 20%
