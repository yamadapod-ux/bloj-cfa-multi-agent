### 4. VaR และ CVaR [CFA L3: Risk Management — VaR / CVaR]

**VaR Parametric (95%, 1-Year Horizon):**
VaR = μ - z × σ
= 8.85% - 1.645 × 30%
= 8.85% - 49.35%
= **-40.5%** (1Y VaR 95%)

**ที่ราคา $4.80:**
1Y VaR = $4.80 × 40.5% = **-$1.94 per share** (ราคาลงไปที่ ~$2.86)

**CVaR / Expected Shortfall (95%):**
CVaR ≈ μ - (φ(z)/α) × σ
≈ 8.85% - (0.103/0.05) × 30%
= 8.85% - 61.8%
= **-52.9%** (ถ้าเกิด worst 5% scenario)

**Maximum Drawdown (Historical):**
- NOK 52W Low: $3.12 [Source: Atlas Data Package — Yahoo Finance]
- NOK Recent Price: $4.80
- จาก 2021 high ~$6.30 → 2023 low ~$3.12 = **Max Drawdown -50.5%**

### 7. Kelly Criterion + Position Sizing [CFA L3: Portfolio Management — Kelly Criterion]

**Kelly Formula:**
f* = (p × b - q) / b
where: p = prob win, b = odds (gain/loss ratio), q = 1-p

**จาก P-W EV:**
- Expected upside: $9.96 - $4.80 = +$5.16 (+107.5%)
- Downside (stop loss): $4.80 - $3.50 (Bear floor) = -$1.30 (-27.1%)
  [Bear floor = VaR 95% extreme = ~$3.50]

- p = 0.70 (prob ราคาไป FV หรือ upside — จาก 20/25 scenarios เป็น upside)
- b = 107.5% / 27.1% = 3.97x (reward-to-risk)
- q = 0.30

**Full Kelly = (0.70 × 3.97 - 0.30) / 3.97 = (2.779 - 0.30) / 3.97 = 2.479 / 3.97 = 62.5%**

**Full Kelly 62.5% = ไม่สมเหตุสมผล** (ขนาดพอร์ตจะไม่ diversify + ความไม่แน่นอนสูง)

**Quarter-Kelly = 62.5% × 25% = 15.6%**

**ปรับลด (Tail Correction + Sector Mismatch):**
- Nokia เป็น sector แปลก (ไม่ใช่ US tech/growth ที่พอร์ตถนัด): -50%
- Narrow Moat (เสี่ยง deteriorate): -20%
- ADR Currency Risk: -10%
- **Final Position Size = 15.6% × (1-0.5) × (1-0.2) × (1-0.1) ≈ 15.6% × 0.36 ≈ 5.6%**

**แต่: พิจารณา Portfolio Concentration:**
- พอร์ตปัจจุบัน Semiconductor 19% (ใกล้ ceiling 20%)
- Telecom Equipment = ไม่ใช่ core sector → limit conservatively
- **Quinn Recommended Max: 1.5–2.0% portfolio** (conservative สำหรับ unusual sector)
