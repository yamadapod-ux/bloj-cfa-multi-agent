**Risk-Free Rate:** 4.3% (current 10Y Treasury)
**Estimated Actual VEEV Return (3Y avg):** ~15.0%/yr (Healthcare SaaS outperformance)
**Jensen's Alpha:** 15.0% - (4.3% + 9.4%) = **+5.3%/yr** (t-stat ~1.9 — significant at 90% CI)

**Interpretation:** VEEV generates ~5.3%/yr excess return above what 4 factors predict. This is consistent with genuine economic moat creating persistent alpha. Comparable to AVGO (+5%/yr) but higher t-stat than MRVL (+3.8%, t=1.48).

**Caveat:** Healthcare/Pharma factor not included in standard Carhart model. If we add a "Healthcare SaaS" factor, alpha may partially collapse (similar to RKLB's defense factor test). Recommend monitoring.

## 4. Sensitivity Matrix 5x5 — Revenue CAGR × FCF Margin [CFA L2: Scenario Analysis]

### Variable Selection Rationale
- **Variable 1 (Revenue CAGR FY2026-2030):** VEEV is transitioning from hypergrowth → sustainable SaaS. Growth deceleration (26% → 16% → target 14%) = primary valuation uncertainty
- **Variable 2 (FCF Margin FY2030):** VEEV's Non-GAAP FCF margin ~51% is exceptional, but GAAP FCF ~31% is more conservative. The path to margin normalization (as R&D investment continues) = key profitability driver
