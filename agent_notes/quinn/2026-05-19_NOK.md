### Kelly Criterion [CFA L3: Portfolio Management — Kelly Criterion]

Kelly Formula: K = (p × b - q) / b
- p = probability FV > price = **56%** (ตาม sensitivity matrix)
- q = 1 - p = 44%
- b = avg upside / avg downside ratio: avg upside cells (+25%) / avg downside cells (-30%) = 0.83x

K = (0.56 × 0.83 - 0.44) / 0.83 = (0.465 - 0.44) / 0.83 = **0.025 / 0.83 = ~3%**

**Quarter-Kelly = 0.75%** → ต่ำมาก; Regime TC × 0.75 = **0.56%** = แทบไม่มีนัย

**Kelly Verdict:** Positive แต่ tiny → Regime TC + max position แต่เดิม 1.5% × 0.75 = 1.125% → ไม่ควร add new
