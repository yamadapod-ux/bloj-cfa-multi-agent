## 4. Kelly Criterion & Position Sizing [CFA L3: Portfolio Construction — Kelly Criterion]

### Kelly Calculation:
- **Expected return (P-W EV → $205 from Quinn):** (205-166)/166 = 23.5% upside
- **Downside (Bear scenario):** $110 Bear FV → (110-166)/166 = -33.7% downside
- **Kelly = (p × b − q) / b** where b = avg upside/downside ratio
  - Win probability (p) = 0.60 (based on scenario weighting — Emma Bull/Base = 60% combined)
  - Loss probability (q) = 0.40 (Bear + Extreme = 40%)
  - b = gain/loss ratio = 23.5% / 33.7% = 0.70
  - **Full Kelly = (0.60 × 0.70 − 0.40) / 0.70 = (0.42 − 0.40) / 0.70 = 0.02 / 0.70 = 2.9%**
  - **Quarter-Kelly = 0.73%** → round to **1%** initial position (conservative sizing signal)

**Kelly interpretation:** Low Kelly reflects thin MOS at $166 vs DCF base $170. Emma base case is only marginally above current price. Upside is large in Bull/Peer scenarios ($222-287) but probability-weighted return is modest. Quarter-Kelly = 1% signals SMALL INITIAL position, NOT avoid.

## 7. Hypothesis Test — Outperformance [CFA L1: Quantitative Methods — Hypothesis Testing]

**H₀:** VEEV expected return = S&P 500 expected return (no alpha)
**H₁:** VEEV expected return > S&P 500 (positive alpha)

**Test: One-tailed t-test on 3Y monthly excess returns**
- Mean monthly excess return (VEEV vs SPX): +0.41%
- Standard deviation of monthly excess return: 4.8%
- n = 36 months
- t = 0.41 / (4.8 / √36) = 0.41 / 0.80 = **0.51**
- t-critical (5%, one-tail, df=35) = 1.69
- **t = 0.51 < 1.69 → Fail to reject H₀** at 5% level

*Interpretation: VEEV's historical outperformance is NOT statistically significant at 5% level by raw return test. Alpha significance in Carhart (t=2.1) is higher because factor-adjusting removes beta contribution (the correct test). Quinn prefers Carhart result.*
