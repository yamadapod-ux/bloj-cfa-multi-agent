## 7. Hypothesis Test — Outperformance [CFA L1: Quantitative Methods — Hypothesis Testing]

**H₀:** VEEV expected return = S&P 500 expected return (no alpha)
**H₁:** VEEV expected return > S&P 500 (positive alpha)

**Test: One-tailed t-test on 3Y monthly excess returns**
- Mean monthly excess return (VEEV vs SPX): +0.41%
- Standard deviation of monthly excess return: 4.8%
- n = 36 months
- t = 0.41 / (4.8 / √36) = 0.41 / 0.80 = **0.51**
- t-critical (5%, one-tail, df=35) = 1.69
- **t = 0.51 < 1.69 → Fail to reject H₀** at 5% level

*Interpretation: VEEV's historical outperformance is NOT statistically significant at 5% level by raw return test. Alpha significance in Carhart (t=2.1) is higher because factor-adjusting removes beta contribution (the correct test). Quinn prefers Carhart result.*

- Avg upside (win scenarios) = +14.2%, Avg downside (loss scenarios) = -29.4%
- b = 14.2%/29.4% = 0.482
- **Full Kelly = (0.50×0.482 − 0.50)/0.482 = -53.6%**
- **Quarter-Kelly = -13.4%**

**Kelly interpretation:** **NEGATIVE Kelly = quant edge เป็นลบที่ราคานี้** — เปลี่ยนจาก v1 (+1% Quarter-Kelly, thin แต่ positive) เป็น negative edge ชัดเจน สัญญาณนี้บอกว่า ณ ราคา $251 risk/reward แบบ probability-weighted ไม่ favorable สำหรับการเพิ่ม position ใหม่ — **ไม่ใช่สัญญาณ panic-sell แต่เป็นสัญญาณ "ห้ามซื้อเพิ่มที่ราคานี้"** เทียบกับ DCF base case single-point ($261.5, MOS +4.2%) ที่ยังเป็นบวกเล็กน้อย — ความแตกต่างนี้สำคัญ: **base-case DCF เพียงอย่างเดียวยัง marginally positive แต่ probability-weighted (รวม downside scenarios) เป็นลบ** — สะท้อนว่า downside tail (Bear/Extreme) มี weight และ magnitude มากพอที่จะดึง expected value ต่ำกว่าราคาตลาด
