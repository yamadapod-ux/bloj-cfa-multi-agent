**Implication:** CRDO Beta 3.20 คือ **beta สูงที่สุดในพอร์ตทั้งหมดจนถึงปัจจุบัน** — สูงกว่า RKLB (สถิติเดิม 2.10) ถึง +52% และสูงกว่า NVDA เกือบ 2 เท่า ความหมายเชิงปริมาณ:

1. **Sharpe Ratio:** ภายใต้ pure-CAPM assumption (ไม่มี idiosyncratic risk) Sharpe ratio ของหุ้นที่ beta สูงจะ**เท่ากับ**ตลาดเสมอ (numerator และ denominator scale ด้วย beta เท่ากัน หักล้างกัน) — นี่คือเหตุผลว่าทำไม Beta สูงไม่ได้แปลว่า Sharpe แย่โดยอัตโนมัติ **แต่** CRDO มี idiosyncratic risk สูงมาก (customer concentration, single-product-cycle, AEC→optical mix shift ตาม Atlas Section I) ที่ไม่ถูก capture ใน beta → total volatility จริงมากกว่า beta-scaled systematic vol อย่างมีนัยสำคัญ → Sharpe ที่แท้จริงต่ำกว่าที่ CAPM-only จะบอก (ดู Section 2)
2. **Position Sizing:** Beta 3.20 หมายความว่าทุก 1% ที่ตลาดขยับ CRDO เคลื่อนไหวเฉลี่ย 3.2% (systematic component) — ที่ portfolio position size เดียวกัน (เช่น 5%) CRDO จะเพิ่ม portfolio-level systematic risk มากกว่า NVDA ที่ position size เท่ากันเกือบ 2 เท่า → ต้อง **ลด position size เทียบสัดส่วน beta** เพื่อรักษา portfolio-level risk contribution ให้เท่ากัน (risk parity logic)
3. **Kelly Criterion:** Kelly formula (f* = μ_excess/σ²) มี σ² อยู่ใน denominator — beta สูงมักมาพร้อม σ สูง (สมมติ idiosyncratic คงที่) ทำให้ Kelly-optimal fraction ลดลงตามธรรมชาติแม้ edge (μ) จะเท่าเดิม — CRDO's high beta จึงกดดัน Kelly ให้เล็กลงโดยตัว mathematics เอง ก่อนจะพิจารณา valuation เลยด้วยซ้ำ

### 5. Kelly Criterion [CFA L3: Portfolio Construction — Kelly Criterion]

**Method A — Continuous Kelly (probability-weighted scenario distribution):**
```python
# f* = (E[R] - Rf) / Variance[R]  — continuous approximation
returns = {"Bull": 0.4271, "Base": -0.1513, "Bear": -0.6058, "Extreme Bear": -0.8272}
probs   = {"Bull": 0.20,   "Base": 0.45,    "Bear": 0.25,    "Extreme Bear": 0.10}

E[R]  = Σ p×r = -21.69%
Var[R] = Σ p×(r - E[R])²  = 0.1599  →  σ = 39.99%

excess = E[R] - Rf = -21.69% - 4.49% = -26.18%
Kelly f* = excess / Var[R] = -0.2618 / 0.1599 = -163.7%
Quarter-Kelly = -40.9%
```

**Method B — Discrete Kelly (Bull vs probability-weighted "other" — MCO-style cross-check):**
```python
p_bull = 0.20
b = 42.71%  # Bull return
weighted_other_FV = (0.45×205.30 + 0.25×95.36 + 0.10×41.81) / 0.80 = $150.51
a = 150.51/241.91 - 1 = -37.78%
Kelly = (0.20×0.4271 - 0.80×0.3778) / 0.4271 = -50.8%
```

**Kelly = NEGATIVE ทั้งสอง method (-51% ถึง -164% ก่อน scale)** → **ไม่มีเหตุผลเชิง probability ในการเปิด position ใหม่ที่ราคา $241.91**

Kelly negative เพราะ P-W EV ($189.45) < ราคาปัจจุบัน ($241.91) — expected value เป็นลบ ก่อนจะพิจารณาเรื่อง beta/vol สูงด้วยซ้ำ นี่คือสัญญาณ**ชัดเจนที่สุด**ในชุดคำนวณทั้งหมด: ที่ราคานี้ ไม่มี mathematical edge สนับสนุนการเข้า position ใหม่

**Breakeven check:** Kelly จะเริ่มเป็นบวกได้ต้องการราคาต่ำกว่า P-W EV $189.45 อย่างมีนัยสำคัญ (ideally มี margin of safety) — **Entry zone เชิง quant ควรอยู่ต่ำกว่า $190** ไม่ใช่ราคาปัจจุบัน
