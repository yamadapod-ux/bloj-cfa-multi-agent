## Section 5: Kelly Criterion [CFA L3: Portfolio Construction — Kelly]

**Kelly Formula:** f* = (p × b − q) / b
where: p = probability of win, q = 1-p, b = ratio of win to loss

**v2 Kelly Calculation:**

ใช้ scenario distribution:
- "Win" scenarios (FV > $228): Bull $305 + Base $243 = weighted avg $258 = +13.2% upside
- "Loss" scenarios (FV < $228): Bear $185 + Extreme $125 = weighted avg $171 = -25% downside
- p (probability of win) = Bull 20% + Base 45% = **65%**
- q = 35%
- b = 13.2% / 25% = 0.53

Kelly f* = (0.65 × 0.53 − 0.35) / 0.53 = (0.345 − 0.35) / 0.53 = **-0.009** → effectively **ZERO / NEGATIVE**

**Quarter-Kelly: 0% theoretical → 0–2% range** (minimal)

**v1 vs v2 Kelly:**
- v1 Kelly was positive (~25% raw → 5% quarter-kelly)
- v2 Kelly ≈ 0 — ราคาปัจจุบัน ≈ P-W EV → Kelly says "don't add, don't full exit"
- **Practical Position:** HOLD existing 5% (if already own from v1 BUY); ห้ามเพิ่ม position ที่ $228; รอ pullback ก่อน
