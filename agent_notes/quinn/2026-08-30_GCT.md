## 4. Risk Metrics

### 4.1 CAPM Expected Return [CFA L1: Portfolio Management — CAPM]
```
E(R)_systematic = Rf + β × ERP = 4.68% + 1.60 × 4.5% = 11.88% annualized
(β 1.64, ERP 5.0% → 12.88%   |   β 1.40, ERP 4.5% → 10.98%)
Total required return (incl. size + company-specific premia) = 13.9%
```

### 4.2 Forward Sharpe Ratio [CFA L1: Portfolio Management — Risk-Adjusted Performance]
```
Vol proxy: micro-cap realized vol ~45–55% (β 1.60 × market σ ~15% ≈ 24% systematic + large idiosyncratic).
Forward Sharpe (CAPM E(R) 11.88%, σ 50%) = (11.88% − 4.68%) / 50% = 0.14
   (σ 45% → 0.16   |   σ 55% → 0.13)
S&P 500 benchmark CAPM Sharpe ≈ (8.98% − 4.68%) / 14.5% ≈ 0.30
```
→ **GCT forward Sharpe ~0.14 = roughly half the market's.** High beta lifts expected return, but ~50% single-stock vol consumes the entire premium. Same pattern as the book's other high-beta names (RKLB 0.42, CRDO — Beta 3.20). The value gap (§6) does not show up in a systematic-risk Sharpe.

### 4.3 Scenario-Based Sharpe / Sortino [CFA L2/L3: Sortino Ratio]
*(from §6 scenario set; 5-yr horizon, annualized)*
```
Scenario annualized returns:  Bull +14.6%  |  Base +5.1%  |  Bear −9.1%
E[ann return]        = 0.25(14.6%) + 0.45(5.1%) + 0.30(−9.1%) = +3.2%
SD (annualized)      = 8.9%
Downside deviation (MAR = 0) = 5.0%
Scenario Sharpe  = (3.2% − 4.68%) / 8.9%  = −0.16
Scenario Sortino = (3.2% − 4.68%) / 5.0%  = −0.30
```
→ **Both marginally negative** — because the probability-weighted 5-year annualized return (~3.2%) sits just **below** the risk-free rate once the 30%-weighted Bear is included, despite the large point-in-time MOS. This is the core tension of the GCT thesis (see §4.4 note and §13).

**⚠️ Horizon sensitivity (ADI/NET discipline):** if FV convergence is assumed over **3 years** instead of 5 (more realistic for a re-rating of an already-cheap stock), scenario annualized returns become Bull +25.5% / Base +8.6% / Bear −14.5%, E[ann] ≈ **+5.9%** (above cash), Scenario Sharpe ≈ **+0.13**. **The sign of the risk-adjusted metric flips on the convergence-horizon assumption — Charlie should not let the verdict pivot on this.** The robust facts are the +25.7% P-W MOS and the positive Kelly.

### 4.7 Kelly Criterion [CFA L3: Portfolio Management — Optimal Position Sizing *(ยังไม่เรียนในหลักสูตรมาตรฐาน — Kelly ใช้ probability/odds กำหนดสัดส่วน bet ที่ maximize long-run log growth)*]
