### 4. CAPM Expected Return

```
E(R_ICE) = Rf + β × ERP
```

**Method A (ERP-based, standard CFA convention):**
E(R_ICE) = 4.67% + 0.925 × 4.23% = **8.58%**

**Method B (trailing market return — alternative, more volatile/less standard):**
E(R_ICE) = 4.67% + 0.925 × (21.41% − 4.67%) = **20.15%**

*ความต่างมหาศาลระหว่าง 2 method (8.58% vs 20.15%) สะท้อนว่า CAPM output sensitivity สูงมากต่อ ERP assumption — trailing 12M S&P 500 return ปีนี้ (+21.41%) สูงกว่า long-run average มาก (สะท้อน RISK-ON regime ปัจจุบัน, S&P 500 ทำ record close ต่อเนื่อง) ใช้ Method A (ERP-based) เป็นหลักเพราะเป็น forward-looking / mean-reverting assumption ตามมาตรฐาน CFA — Method B ใช้เป็น upper-bound sensitivity เท่านั้น* [CFA L1: Portfolio Management — CAPM sensitivity to ERP assumption]
