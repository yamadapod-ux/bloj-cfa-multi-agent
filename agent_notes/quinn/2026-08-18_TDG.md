# Quinn's Notes — TDG (TransDigm Group Incorporated) (2026-08-18)

## Methodology

TDG มีจุดพิเศษที่ทำให้ standard quant framework ใช้ตรงๆ ไม่ได้ 2 จุด:

1. **Shareholders' Equity ติดลบ (-$9,719M)** — เกิดจาก aggressive debt-funded buyback + special dividend history (annual dividend $90/share, yield ~7.3% ล่าสุด — confirmed จาก stockanalysis.com) → ROE ไม่มีความหมาย, D/E ไม่มีความหมาย (numerator/denominator sign ผิด), และ book-value-weighted WACC ใช้ไม่ได้
2. **ไม่มี full historical daily/monthly price series ให้ WebSearch ได้ตรงๆ** → ใช้ **beta ที่ verified แล้ว (0.91, 5Y monthly, Yahoo Finance)** เป็นฐาน + สร้าง annualized volatility จาก 2 independent proxy sources แล้ว cross-validate กับ 3rd source (TradingKey 240-day realized vol) — บังเอิญ (หรือไม่บังเอิญ) ทั้ง 3 วิธี converge ที่ ~28.5-28.8% ซึ่งให้ความมั่นใจว่าตัวเลขนี้ใช้ได้

**การแก้ปัญหา methodology:**
- **WACC**: ใช้ **market-value weights** (Market Cap สำหรับ Equity, ไม่ใช่ book equity) แทน book-value weights — Market Cap เป็นบวกเสมอ ($68.5B) แม้ book equity ติดลบ วิธีนี้คือ standard CFA practice อยู่แล้ว (WACC ควรใช้ market value ไม่ใช่ book value เสมอ ไม่ใช่แค่กรณีพิเศษของ TDG) — negative equity แค่ทำให้ practitioner จำนวนมากพลาดใช้ book weight โดยไม่รู้ตัว
- **Leverage**: ใช้ **Net Debt/EBITDA (5.81x)** แทน D/E — เป็น metric มาตรฐานที่ credit rating agencies และ TDG เองใช้ใน covenant (สอดคล้องกับ company's own "EBITDA As Defined" reporting)
- **Valuation**: ใช้ **EV-based 3-year FCF + terminal EV/EBITDA multiple** แทน equity-based DCF ตรงๆ — คำนวณ Enterprise Value ก่อน แล้ว bridge ไปหา Equity Value ด้วย `EV - Net Debt` (ไม่ผ่าน book equity เลย)

### Sharpe Ratio (1Y)

```
Sharpe = (Total Return - Rf_3M) / σ = (-3.80% - 3.79%) / 28.55% = -0.27
```
**Cross-check:** External aggregators รายงาน Sharpe -0.20 ถึง -0.28 ([portfolioslab.com](https://portfolioslab.com/tools/stock-comparison/TDG/PGR), [tradingkey.com](https://www.tradingkey.com/markets/stocks/tdg/risk-assesment)) — **ตรงกับ calculation ของเรา (-0.27) เกือบสนิท** → high confidence ในตัวเลขนี้

**การประเมิน:** Sharpe ติดลบ = แย่มาก บนพื้นฐาน CFA framework (Sharpe < 0 หมายความว่าผลตอบแทนต่ำกว่า risk-free rate หลังปรับความเสี่ยงแล้ว) แต่นี่คือ **1-year snapshot ที่บิดเบือนโดย idiosyncratic derating event** (Stifel downgrade + right-to-repair concern) ไม่ใช่ reflection ของ business quality ระยะยาว — ROIC 19.40% (trending ขึ้นต่อเนื่อง 3 ไตรมาส) บอกเรื่องราวตรงข้ามกับ Sharpe 1Y

### Sortino Ratio (parametric approximation)

```
Downside Deviation ≈ σ/√2 = 28.55%/1.414 = 20.19%  (assumption: ~normal distribution, target=mean)
Sortino = (-3.80% - 3.79%) / 20.19% = -0.38
```
**⚠️ Limitation:** นี่คือ parametric approximation ไม่ใช่ empirical downside deviation จริง เพราะไม่มี full monthly return series ให้ WebSearch/compute ตรงๆ ในรอบนี้ ถ้าต้องการ Sortino ที่แม่นยำ ต้องการ TDG monthly returns 3-5 ปีย้อนหลัง [CFA L1: Portfolio Management — Sortino Ratio, Downside Deviation]

### VaR / CVaR (Parametric, 1-day, 95%)

```
Daily σ = 28.55%/√252 = 1.80%
VaR 95% (1-day) = 1.645 × 1.80% = -2.96%
CVaR 95% (1-day, Expected Shortfall) = σ_daily × φ(1.645)/0.05 = -3.71%
```
Cross-check: TradingKey reports VaR = -2.62% (independent, methodology อาจต่างกันเล็กน้อย — order of magnitude ตรงกัน)

### Single-Period "Realized Alpha" (ไม่ใช่ Carhart 4-Factor — ดู Limitation)

```
CAPM Expected Return (1Y) = Rf_3M + β×(Rm - Rf_3M)
  = 3.79% + 0.91 × (20.5% - 3.79%)   [Rm = S&P500 1Y total return ~20.4-20.8%, slickcharts.com WebSearch]
  = 3.79% + 15.21% = 19.00%

Realized Alpha = Actual Total Return - CAPM Expected
  = -3.80% - 19.00% = -22.80%
```

**⚠️ Critical Limitation:** นี่คือ single-period (n=1) realized deviation ไม่ใช่ statistically-tested Jensen's Alpha (ต้องการ regression บน monthly returns หลายปี พร้อม t-stat) และไม่ใช่ Carhart 4-factor alpha (ต้องการ SMB/HML/MOM factor loadings ซึ่งไม่มีข้อมูลในรอบนี้) **ข้อมูลไม่พอสำหรับ proper Carhart regression — DATA NOT AVAILABLE**

**แต่ magnitude นี้สำคัญมาก:** -22.8% divergence จาก CAPM prediction ยืนยันสิ่งที่ Atlas Macro Brief พูดถูก — TDG's ความเสี่ยงหลักปีนี้คือ **idiosyncratic (regulatory/valuation derating)** ไม่ใช่ systematic (beta 0.91 ทำนายว่าควร track ตลาดใกล้เคียง แต่ตลาด +20.5% ขณะที่ TDG -3.8% total return) [CFA L2: Corporate Finance — Alpha Decomposition, Systematic vs Idiosyncratic Risk]
