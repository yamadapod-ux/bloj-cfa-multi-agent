## Methodology [CFA L2: Equity Valuation — Method Selection]

Insurance ต้องใช้ valuation framework ต่างจาก operating company ปกติ — เน้น **P/B–ROE relationship** และ **normalized-earnings P/E** ไม่ใช่ DCF/EV-multiples (EV ไม่มีความหมายสำหรับ insurer เพราะ debt = operating leverage / float, ไม่ใช่ financing) [CFA L2: Equity — Financial Institutions]. กรอบที่เลือก:

1. **P/B–ROE justified multiple** (Residual Income foundation) — primary anchor
2. **Normalized-earnings P/E** (reduced-form: Combined Ratio + Premium Growth → EPS → fair P/E) — sensitivity engine
3. **Peer-relative P/E** cross-check (CB/EG/RNR/TRV)
4. **Earnings yield vs risk-free** — cheapness screen
5. **CAPM / beta** — risk + portfolio-construction lens (ไม่ใช้ตั้ง FV — เหตุผลด้านล่าง)

**เหตุผลที่ไม่ใช้ CAPM ตั้ง Ke สำหรับ valuation:** Beta 0.31 → Ke(CAPM) = 4.35% + 0.31×4.5% = **5.74%** ซึ่งต่ำกว่า long-run growth ที่สมเหตุสมผล → Gordon model ระเบิด (g > Ke). ใช้ **empirical Ke = 9–10%** แทน (build-up: rf 4.35% + equity premium ~4.65–5.65% สำหรับ P&C insurer ที่ underwriting cyclical แม้ market beta ต่ำ). Bear ใช้ 10%. *[CFA L2: Cost of Capital — Beta limitations for low-beta financials]*

| Metric | Value | Note |

| Forward Sharpe (CAPM return) | **0.06–0.08** | (Ke−rf)/σ ที่ σ 18–22% — ต่ำ เพราะ CAPM ให้ excess return แค่ ~1.4% |

**สำคัญ — Sharpe paradox ของ low-beta stock:** ถ้าใช้ CAPM expected return (5.74%) → forward Sharpe เพียง 0.06–0.08 (ต่ำกว่า S&P 500 ~0.55 มาก) เพราะ CAPM "ลงโทษ" beta ต่ำด้วยการให้ expected return ต่ำ. **แต่นี่คือจุดที่ CAPM ล้มเหลวกับ low-vol anomaly** — empirically low-beta stocks ให้ risk-adjusted return *สูงกว่า* ที่ CAPM ทำนาย (Low-Volatility Anomaly, Frazzini-Pedersen "Betting Against Beta"). [CFA L2: Market Anomalies — Low-Vol Anomaly] *(ยังไม่เรียน — BAB factor: หุ้น beta ต่ำให้ alpha เป็นบวกอย่างเป็นระบบ ขัดกับ CAPM)*

→ **Realistic forward Sharpe ใช้ earnings-power return:** earnings yield 14.2% + premium growth ทำให้ total return potential ~10–13% ที่ σ ต่ำ (18–20%) → **Sharpe ~0.30–0.45** ซึ่งใกล้เคียง defensive peer และดีในแง่ drawdown protection.

**Downside risk:** Beta 0.31 → ในการลงของตลาด -10%, ACGL คาดลด ~-3.1% (systematic). Idiosyncratic downside = **cat year + soft cycle** (CR > 95% + reserve releases หมด) ไม่ใช่ market risk. นี่คือ key — ความเสี่ยงหลักของ insurer = underwriting/cat tail ไม่ใช่ beta.
