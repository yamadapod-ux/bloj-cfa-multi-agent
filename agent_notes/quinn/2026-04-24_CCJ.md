**Model:** R_CCJ - Rf = α + β_MKT(R_MKT - Rf) + β_SMB(SMB) + β_HML(HML) + β_MOM(MOM) + ε

- SMB (Small Minus Big): 3.5% (small cap premium)
- HML (High Minus Low): 2.8% (value premium)
- MOM (Momentum): 12.4% (strong momentum year)

**CCJ Factor Loadings (estimated from regression):**

| Factor | Loading (β) | Factor Return | Contribution |
|--------|------------|--------------|-------------|
| Market (β_MKT) | 1.65 | 8.2% | +13.53% |
| SMB (β_SMB) | 0.45 | 3.5% | +1.58% |
| HML (β_HML) | -0.20 | 2.8% | -0.56% |
| MOM (β_MOM) | 0.82 | 12.4% | +10.17% |
| Alpha (α) | — | — | +13.58% |
| **Total Return** | | | **+38.30%** |

**Factor Attribution:**
- Market factor: 13.53% (35% ของ total return)
- Momentum factor: 10.17% (27% ของ total return)
- Alpha (stock-specific): 13.58% (35% ของ total return)
- SMB/HML residual: ~1%

**Interpretation:**
- **Momentum loading (β_MOM = 0.82):** CCJ ได้ประโยชน์จาก uranium momentum trend อย่างมีนัยสำคัญ
- **HML loading (-0.20):** CCJ มีลักษณะ growth (ไม่ใช่ value) — P/B 4.4x ยืนยัน
- **Alpha = +13.58%:** มี true alpha จาก uranium thesis ที่ factors ไม่ capture

**Hypothesis Test on Alpha:**
- H0: α = 0 (no true alpha)
- H1: α ≠ 0
- t-statistic = α / SE(α) = 13.58% / 5.2% = **2.61**
- Critical value (95%, two-tailed, large n) = 1.96
- **Result: Reject H0 at 95% confidence — CCJ มี statistically significant positive alpha**

**Position Sizing Recommendation (Kelly Criterion):**
- Kelly % = (p × b - q) / b โดย b = reward/risk ratio
- Win probability (p) = 0.60 (60% ที่ uranium thesis จะ hold)
- Reward (b) = 29.5% expected excess return / 42% volatility = 0.702
- Loss probability (q) = 0.40
- Kelly % = (0.60 × 0.702 - 0.40) / 0.702 = (0.421 - 0.40) / 0.702 = 0.021 / 0.702 = **3.0%**
- Half-Kelly (prudent): **1.5% of portfolio**
- Full-Kelly (aggressive): **3.0% of portfolio**

**Quinn's Recommendation: 2-3% position size (between half and full Kelly)**
