## Methodology

1. **Probability-Weighted Expected Value (P-W EV)** — ใช้ FY27E Adjusted EPS (จาก FY26 guide + growth assumption) × Exit Forward P/E multiple ใน 3 scenarios (Bull/Base/Bear) — เลือก EPS × multiple แทน DCF เพราะ ETN อยู่ใน **Growth bucket** (data center capex theme, revenue growth >20% TTM) ตาม IPS Framework Buckets และ Atlas เตือนชัดเจนว่าประเด็นหลักตอนนี้คือ **valuation/multiple risk** ไม่ใช่แค่ earnings risk — จึงต้องมี exit-multiple เป็นตัวแปรอิสระในโมเดล ไม่ผูกกับ current multiple คงที่
2. **Sensitivity Matrix: FY27 EPS Growth Rate × Exit Forward P/E** — เลือกคู่นี้แทน "Data Center Backlog Growth × Margin Expansion" ตามที่โจทย์เสนอ เพราะ **backlog 307GW เป็น single-point snapshot ไม่มี time-series** ใน Data Package [Atlas Data Package Section H] จึงไม่สามารถสร้าง "backlog growth rate" ที่มี base เทียบได้ — ใช้ FY27 EPS Growth (proxy สำหรับ backlog-to-revenue conversion pace + organic growth guide) และ Exit Forward P/E (ตัวแปรที่ Atlas ระบุว่าเป็นความเสี่ยงหลักหลัง +14.9% rally สู่ 98.4% ของ 52W high) แทน — เป็นคู่ตัวแปรที่ตลาดกำลังถกเถียงกันจริงในหุ้นนี้ ณ จุดนี้ (จะ sustain 11-13% organic growth ต่อได้ไหม + จะ de-rate จาก 30x forward P/E ไหม)

**Risk metrics:** ไม่มี historical daily/monthly price series ใน Data Package และ scope งานนี้ห้าม WebSearch/WebFetch ใหม่ — จึงใช้ **Beta (1.18) + CAPM approximation** สำหรับ Sharpe/Treynor แบบ ex-ante, และใช้ **P-W EV scenario-implied returns** (จาก framework ข้อ 1) เป็น proxy ของ expected-return distribution สำหรับ Sortino/downside estimate แทน historical return series จริง — **assumption ทุกตัวถูก flag ชัดเจนว่าไม่ได้ WebSearch ใน session นี้**

| Scenario | FY26 EPS | FY27 Growth Assumption | FY27E EPS | Exit Fwd P/E | Fair Value | Probability |

| **Bear** | $13.40 (guide low) | 6% (AI capex digestion, tougher comps, backlog conversion delay) | $14.20 | 24.0x (mean-reversion จาก multiple ที่ยืดตึงหลัง +14.9% rally) | **$340.90** | 25% |

### 2. Risk-Adjusted Return Metrics

**Inputs:**
- Beta = 1.18 [Atlas Data Package Section F, Stockanalysis.com]
- Rf = 4.68% (10Y Treasury, Aug 4 2026) [Atlas Data Package Section F, อ้างอิง 2026-08-02_regime.md]
- Market Risk Premium = **5.5%** *(ASSUMPTION — long-run US equity risk premium, ไม่ได้ WebSearch ใน session นี้ตาม scope งาน, ใช้ตัวเลขกลางของช่วงที่มักอ้างอิงในอุตสาหกรรม 4-6% — ต้อง verify แหล่งที่มาจริงก่อนใช้ตัดสินใจ deploy)*
- σ_market (long-run S&P 500 annualized) = **15%** *(ASSUMPTION เดียวกัน — ไม่ได้ sourced session นี้)*
- σ_ETN (approx) = Beta × σ_market = 1.18 × 15% = **17.7%** *(simplification — สมมติ correlation ≈ 1 กับตลาด ซึ่งจะ**underestimate**ความเสี่ยงจริง เพราะไม่รวม idiosyncratic risk — ใช้เป็น lower-bound proxy เท่านั้น)*

```python
capm_er = rf + beta*mrp_assumption  # = 4.68% + 1.18×5.5% = 11.17%
sharpe_capm = (capm_er - rf) / sigma_etn        # = (11.17-4.68)/17.7 = 0.367
treynor_capm = (capm_er - rf) / beta            # = 6.49%/1.18 = 5.50% (≡ MRP, tautological ภายใต้ CAPM — ไม่มีนัยสำคัญเพิ่ม)
```

**CAPM-based (required return framework):**
- Sharpe Ratio ≈ **0.367** (พอใช้ตามเกณฑ์ >0 แต่ต่ำกว่า 1.0)
- Treynor Ratio ≈ **5.50%** (เท่ากับ MRP assumption พอดี — เป็น artifact ของสูตร ไม่ใช่ signal จริง)

**P-W EV-implied (Quinn's own scenario model แทน "expected return" จริง — มีความหมายมากกว่า):**

Annualized returns จาก 3 scenarios (horizon ~1.5 ปีถึง FY27 full-year):
| Scenario | Total Return | Annualized Return | Probability |
|----------|--------------|--------------------|--------------|
| Bull | +17.04% | +11.06% | 25% |
| Base | +2.45% | +1.63% | 50% |
| Bear | −23.36% | −16.25% | 25% |

```python
pw_ann_return = Σ(p_i × r_i) = 0.50×1.63% + 0.25×11.06% + 0.25×(-16.25%) = -0.48%
sharpe_pw = (pw_ann_return - rf) / sigma_etn = (-0.48-4.68)/17.7 = -0.292
treynor_pw = (pw_ann_return - rf) / beta       = (-0.48-4.68)/1.18 = -4.38%

# Sortino — downside deviation, MAR = Rf = 4.68%
downside_var = 0.50×min(0, 1.63-4.68)² + 0.25×min(0, 11.06-4.68)² + 0.25×min(0, -16.25-4.68)²
             = 0.50×(-3.05)² + 0.25×0 + 0.25×(-20.93)²
downside_dev = sqrt(downside_var) = 10.68%
sortino_pw = (pw_ann_return - MAR) / downside_dev = (-0.48-4.68)/10.68 = -0.483
```

- **Sharpe (P-W EV implied): −0.292** — negative, สัญญาณลบ
- **Treynor (P-W EV implied): −4.38%** — negative
- **Sortino (P-W EV implied): −0.483** — negative

**Interpretation:** ความขัดแย้งระหว่าง CAPM required return (+11.17%) กับ scenario-implied expected return (−0.48%) คือ **สัญญาณเชิงปริมาณที่สำคัญที่สุดของการวิเคราะห์นี้** — ที่ราคาปัจจุบัน หุ้นให้ expected return ต่ำกว่า risk-free rate ในมุมมอง base-case-weighted scenario ทั้งที่ต้อง require ~11% เพื่อชดเชยความเสี่ยงเชิง systematic (Beta 1.18) → นี่คือเหตุผลเชิงสถิติที่ทำให้ downside-weighted risk premium ติดลบ ไม่ใช่เพราะ business แย่ (fundamentals ยังดีมาก) แต่เพราะ **valuation ที่จ่ายไปแล้วทำให้ไม่มี risk premium เหลือ**

*Limitation ชัดเจน: ทั้งหมดนี้เป็น scenario-based proxy ไม่ใช่ historical realized-return Sharpe/Sortino ที่แท้จริง — ถ้าต้องการ Sharpe เชิง empirical แท้ ต้องมี daily/monthly price series ย้อนหลัง (3-5Y) ซึ่งไม่มีใน Data Package และ scope งานนี้ห้าม WebSearch เพิ่ม*
