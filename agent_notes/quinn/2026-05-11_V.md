**Variable 1 — Revenue CAGR (5-year):** Range 6% → 12%
**Variable 2 — DOJ Structural Remedy Probability:** Range 0% → 40% (probability of severe structural remedy)

*การคำนวณ Fair Value ต่อ cell: ใช้ Emma's DCF framework + DOJ impact haircut*
- Base DCF (no DOJ): Revenue CAGR × WACC model → FV
- DOJ haircut: structural remedy = -25% revenue impact × probability
- Blended FV = DCF_base × (1 - DOJ_prob × 0.35) — approximation

```python
# Sensitivity Matrix Calculation Logic
# Revenue CAGR rows: 6%, 7.5%, 9%, 10.5%, 12%
# DOJ Structural Prob cols: 0%, 10%, 20%, 30%, 40%

import math

def calc_fv(rev_cagr, doj_prob):
    # Base DCF (simplified): higher revenue CAGR → higher FV
    # Base: CAGR 9% → FV $296; linear approximation $20 per CAGR pp
    base_dcf = 296 + (rev_cagr - 0.09) / 0.015 * 20
    # DOJ discount: structural remedy -$90/share (Bear case $190 vs base $296 = $106 gap)
    doj_discount = doj_prob * 106
    return round(base_dcf - doj_discount, 0)

matrix = {}
rev_cagrs = [0.06, 0.075, 0.09, 0.105, 0.12]
doj_probs = [0.0, 0.10, 0.20, 0.30, 0.40]

for r in rev_cagrs:
    row = {}
    for d in doj_probs:
        row[d] = calc_fv(r, d)
    matrix[r] = row
```

## Section 5: Kelly Criterion → Position Sizing [CFA L3: Portfolio Construction — Kelly Criterion]

**Kelly Formula:**
```
f* = (bp - q) / b

where:
b = upside ratio (ถ้าชนะ ได้เท่าไหร่)
p = probability of win (upside scenario)
q = 1 - p = probability of loss

Base Case analysis at $337:
- Bull (35%): return = ($380 - $337) / $337 = +12.8%
- Base (40%): return = ($295 - $337) / $337 = -12.5% → loss scenario
- Bear (20%): return = ($195 - $337) / $337 = -42.1% → severe loss
- Extreme (5%): return = ($130 - $337) / $337 = -61.4% → extreme loss

Expected Value at $337:
E(R) = 35% × 12.8% + 40% × (-12.5%) + 20% × (-42.1%) + 5% × (-61.4%)
E(R) = 4.48% - 5.0% - 8.42% - 3.07%
E(R) = -12.01% → Negative Expected Return at $337

Kelly = NEGATIVE at $337 → ไม่ควรซื้อ ณ ราคานี้
```

**Kelly Result: NEGATIVE at $337** — ยืนยัน v1 ที่ Kelly negative ที่ $355

**What Price Makes Kelly Positive?**
- Kelly = 0 เมื่อ E(R) = 0
- แก้สมการ: ต้องการ price ต่ำพอที่ Bull case return ชดเชย downside
- Estimated Break-even price: ~$295-310 (ใกล้เคียงกับ Emma's entry zone $285-310)

**Quarter-Kelly Position Sizing (หาก entry ที่ $300):**
```
At $300: E(R) = 35% × 26.7% + 40% × (-1.7%) + 20% × (-35%) + 5% × (-56.7%)
E(R) = 9.3% - 0.7% - 7.0% - 2.8% = -1.2% → still slightly negative

At $285: E(R) = 35% × 33.3% + 40% × (+3.5%) + 20% × (-31.6%) + 5% × (-54.4%)
E(R) = 11.7% + 1.4% - 6.3% - 2.7% = +4.1% → positive → Kelly > 0

Quarter-Kelly at $285: est. 1.5-2% (conservative)
```

**Quinn Recommendation for Position Sizing:**
- ณ ราคา $337: Kelly NEGATIVE → ไม่ซื้อ
- ณ entry zone $285-300: Quarter-Kelly ~1.5-2% (conservative เพราะ DOJ uncertainty)
