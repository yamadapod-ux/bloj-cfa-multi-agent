### 5. Kelly Criterion [CFA L3: Portfolio Construction — Kelly]

Since **no scenario (Bull/Base/Bear) produces a positive absolute return** at current price (see Section 2 — even Bull is -2.2%), the binary win/loss Kelly formula used in May breaks down (there is no "win" state to define p against). Switched to the continuous-outcome Kelly approximation:

```
f* = μ / σ²

Scenario-weighted expected return (μ) = 0.20×(-2.18%) + 0.55×(-45.75%) + 0.25×(-73.13%) = -43.88%
Scenario-weighted std dev (σ) = √[0.20×(41.70)² + 0.55×(-1.87)² + 0.25×(-29.25)²] = 23.74%

f* = -0.4388 / (0.2374)² = -0.4388 / 0.05636 = -7.79
```

**Kelly Interpretation:** f* = **-7.79 (deeply negative)** — far more negative than May's already-negative Kelly. Under an unconstrained framework this would signal an aggressive short; under this IPS (long-only, no shorting) it simply confirms **zero position size justified — stronger AVOID signal than May's "negative, no BUY."**

### 6. Sharpe Ratios — Two Variants [CFA L1: Portfolio — Risk-Adjusted Metrics]
*(ยังไม่เรียน — Sharpe ratio วัด excess return ต่อหน่วย total risk (σ) เทียบกับ Treynor ที่ใช้ systematic risk (β) เท่านั้น)*

**(a) Forward Sharpe — CAPM-parity style (same formula as May, for direct comparability):**
```
Forward Sharpe = (CoE − Rf) / σ_annual
                = (13.19% − 4.785%) / 37.5%
                = 0.224
```
*σ_annual = 37.5% carried forward from 2026-05-15 Quinn's notes — **NOT re-verified this session** (WebSearch budget exhausted before historical volatility could be re-confirmed with a fresh source). Flag for full pipeline re-run.*

Compare to May: 0.18 → 0.224. This metric is mechanically β×ERP/σ (i.e., it measures the market's baseline systematic-risk compensation ratio, not QCOM-specific mispricing) — it improved slightly only because β rose proportionally more than it changes the numerator's relationship to σ. **This metric alone is not very informative about QCOM's mispricing — see (b) below for the more decision-relevant number.**

**(b) Quinn DCF-Implied Sharpe-equivalent (new this session, uses Quinn's own scenario dispersion):**
```
DCF-Implied Sharpe = (μ_scenario − Rf) / σ_scenario
                    = (-43.88% − 4.785%) / 23.74%
                    = -2.05
```
*⚠️ Caveat: μ and σ here are 5-year-horizon DCF-scenario-implied figures, not literally annualized realized/historical returns — not directly comparable to a textbook annual Sharpe ratio. Presented as a scenario risk-adjusted mispricing score, not a standard Sharpe.*

**Interpretation:** -2.05 is an extreme negative reading — it says the probability-weighted expected return is not just below the risk-free rate, it is deeply negative in absolute terms while carrying meaningful dispersion. This is the single clearest quant confirmation of the negative MOS finding.
