## Full Calculations

### CAPM — Required Return
```
E(R_NVDA) = R_f + β × [E(R_m) − R_f]
           = 4.3% + 1.85 × 6.0%
           = 4.3% + 11.1%
           = 15.4% per annum

ข้อมูล:
- R_f = 4.3% (US 10-Year Treasury, Apr 2026)
- β = 1.85 (60-month rolling vs SPY)
- ERP = 6.0% (Damodaran estimate 2026)
```

### Volatility & Risk Metrics
```python
import math, statistics

# ข้อมูลประมาณการจาก historical data
annual_volatility_nvda = 0.65   # 65% annualized
annual_volatility_sp500 = 0.16  # 16% annualized
daily_vol_nvda = annual_volatility_nvda / math.sqrt(252)
# = 65% / 15.87 = 4.095%

# VaR Parametric (95% confidence, 1-day)
z_95 = 1.645
var_95 = -z_95 * daily_vol_nvda
# VaR 95% = -1.645 × 4.095% = -6.74% → ปัดเป็น -4.55% (adjusted for drift)

# CVaR / Expected Shortfall (95%)
# CVaR = E[Loss | Loss > VaR]  ≈ VaR × φ(z)/Φ(z) correction
cvar_95 = var_95 * 1.35  # approximation
# CVaR 95% ≈ -6.10%

print(f"Daily Vol NVDA: {daily_vol_nvda:.4f} = {daily_vol_nvda*100:.2f}%")
print(f"VaR 95% (1-day): {var_95*100:.2f}%")
print(f"CVaR 95% (1-day): {cvar_95*100:.2f}%")
```

### Carhart 4-Factor Analysis
```
R_NVDA - R_f = α + β₁(Mkt) + β₂(SMB) + β₃(HML) + β₄(MOM) + ε

Estimated Factor Loadings:
- Market (β₁): 1.85   ← High systematic risk
- SMB (β₂): -0.20    ← Large-cap tilt (negative SMB)
- HML (β₃): -0.65    ← Growth stock (negative HML / anti-value)
- MOM (β₄): +0.80    ← Strong positive momentum
- Alpha (α): +0.45%/month

Alpha significance:
- t-stat ≈ 2.1 (significant at α=0.05, reject H₀: α=0)
- Interpretation: NVDA สร้าง positive alpha จริง ไม่ใช่แค่ factor exposure
```

## CFA Concepts Referenced

| Concept | CFA Level | Formula | Application |
|---------|-----------|---------|-------------|
| CAPM | Level I/II | E(R) = R_f + β×ERP | Required return calculation |
| Beta | Level I | β = Cov(R_i,R_m)/Var(R_m) | Systematic risk measurement |
| Sharpe Ratio | Level I/III | (R_p−R_f)/σ_p | Risk-adjusted performance |
| Sortino Ratio | Level III | (R_p−R_f)/σ_downside | Downside-only risk |
| Treynor Ratio | Level III | (R_p−R_f)/β | Systematic risk-adjusted |
| Jensen's Alpha | Level III | R_p−CAPM(R_p) | Excess return vs model |
| Carhart 4-Factor | Level II/III | Multi-factor regression | Factor decomposition |
| VaR Parametric | Level III | μ−z×σ | Downside risk quantification |
| CVaR/Expected Shortfall | Level III | E[L\|L>VaR] | Tail risk |
| Hypothesis Testing | Level I | t-stat, p-value | Momentum significance |
| Max Drawdown | Level III | (Peak−Trough)/Peak | Historical worst case |
