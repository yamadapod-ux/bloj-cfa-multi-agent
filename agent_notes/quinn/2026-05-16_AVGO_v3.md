## 4. Kelly Criterion [CFA L3: Portfolio Construction — Position Sizing]

```
Kelly = (p × b − q) / b

ใช้ Probability-Weighted EV:
P_bull = 0.50, Return_bull = +25% (FV $243 from base case matrix)
P_base = 0.35, Return_base = +7% (FV $243 at slight premium)
P_bear = 0.15, Return_bear = −25% (Bear $175 scenario)

E(Return) = (0.50 × 25%) + (0.35 × 7%) + (0.15 × −25%)
          = 12.5% + 2.45% − 3.75% = +11.2%

P(win) = 0.85 (combined bull+base), Odds b = 11.2% expected / 25% avg downside risk

Kelly fraction ≈ E(Return) / (Return_bull − 0) = 11.2% / 25% = 44.8%
Quarter-Kelly = 44.8% × 0.25 = 11.2% → too high

[v3 Correction]: Using FORWARD return from $228
Forward Return (base) = +6.6% only (FV $243, not +25%)
Kelly (forward) ≈ 6.6% / (Variance × adjusted) ≈ near 0%
```

**Kelly v3 ≈ ~0–2%** ยืนยัน v2 — ราคา $228 = MOS ต่ำมาก = ไม่มีเหตุผล quant เพิ่ม position
