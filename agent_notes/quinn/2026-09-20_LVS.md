## Full Calculations

### 1. CAPM / Cost of Equity
```
Ke = Rf + β × ERP
Rf = 4.96% [Source: ETF Trends — Treasury Yields Snapshot Sept 11 2026, Atlas-verified]
β  = 0.82  [Source: Yahoo Finance, Atlas Data Package Section F]
ERP = 4.23% [Source: Damodaran Implied ERP, start-of-2026 reading — closest verified figure found this session;
             *(caveat — ไม่ใช่ September reading ที่ update รายเดือน, ใช้เป็น best-available proxy)*]

Ke = 4.96% + 0.82×4.23% = 8.43%
```

### 2. Volatility & Implied Correlation
```
30-Day Historical Volatility (close-to-close) = 25.75% [Source: AlphaQuery.com, 2026-09-18]
90-Day Historical Volatility (close-to-close) = 24.98% [Source: AlphaQuery.com, 2026-09-18]
Average HV used = 25.36%

VIX (proxy for σ_S&P500, implied) = 14.81% [Source: Atlas regime record 2026-09-20, ts2.tech/Yahoo Finance, Sept 18 close]

β = ρ × (σ_LVS/σ_market)  →  ρ = β × (σ_market/σ_LVS)
ρ = 0.82 × (14.81%/25.36%) = 0.479
```
**Insight:** correlation ที่ implied จาก beta (~0.48) ต่ำกว่าค่าเฉลี่ยทั่วไปของหุ้น S&P constituent (~0.6–0.8) — ยืนยันเชิงสถิติสิ่งที่ Atlas ระบุเชิงคุณภาพว่า LVS ขับเคลื่อนโดย Macau/Singapore structural recovery มากกว่า US domestic cycle จึงมี diversification benefit ต่อพอร์ตที่กระจุกตัวในหุ้น US-cycle-driven ตัวอื่น แต่ทั้งนี้ β ต่ำ (0.82) ไม่ได้แปลว่าความเสี่ยงต่ำ — total volatility จริง (25.36%) สูงกว่าที่ beta อย่างเดียวบ่งชี้ เพราะมี idiosyncratic risk สูง (China policy, VIP hold variance, Macau concession risk) ที่ CAPM ไม่จับ — สำคัญมากสำหรับพอร์ตที่ concentrate 8–10 ตำแหน่ง (diversification benefit ทาง theory ไม่เกิดขึ้นเต็มที่ในทางปฏิบัติ)

### 3. Sharpe / Treynor Ratio
```
Sharpe (CAPM ex-ante) = (Ke − Rf) / σ_LVS = (8.43% − 4.96%) / 25.36% = 0.137   [แย่ — reflects low-beta ceiling]
Sharpe (Consensus-PT based, 12M forward, bullish scenario):
   Implied return to PT $59.78 = (59.78−39.98)/39.98 = +49.52%  [Source: Atlas/Charlie data package, 49 analysts avg PT]
   Sharpe = (49.52% − 4.96%) / 25.36% = 1.757   [ยอดเยี่ยม — ถ้า street thesis เกิดขึ้นจริง]

Treynor (CAPM) = (Ke−Rf)/β = 4.23%   *(tautological ภายใต้ pure CAPM assumption — เท่ากับ ERP พอดี เพราะ Ke ถูกสร้างจาก CAPM formula เอง ไม่ใช่ independent信号)*
Treynor (PT-based) = (49.52%−4.96%)/0.82 = 54.35%
```
**Interpretation:** Sharpe แกว่งกว้างมาก (0.14 ex-ante CAPM vs 1.76 ถ้าใช้ street consensus) — ระยะห่างนี้สะท้อนว่า ณ ราคาปัจจุบัน ตลาด (มุมมอง 49 analysts) มองว่า LVS undervalued อย่างมีนัยสำคัญเทียบกับ "fair CAPM return" — แต่ Sharpe-PT-based เป็น **scenario สมมติ ไม่ใช่ historical realized** ต้อง treat เป็น upper-bound ไม่ใช่ตัวเลขที่ใช้ judge risk-adjusted return จริงในอดีต *(หมายเหตุ: ไม่สามารถคำนวณ realized historical Sharpe จาก daily/monthly return series ได้ในรอบนี้ — WebSearch summary ให้ 1Y TSR ขัดแย้งกันเอง +26.48% (Simply Wall St) vs -14.58% TTM (source อื่นไม่ระบุชัด) ไม่ผ่านเกณฑ์ ≥2-source cross-check ที่สอดคล้องกัน จึงไม่ใช้ตัวเลขนี้ในการคำนวณ Sharpe แต่ระบุไว้เป็น data-quality flag)*

### 4. WACC
```
E = Market Cap = $25.895B  |  D = Total Debt = $15.284B  |  V = $41.179B
We = 62.89%  |  Wd = 37.11%
Kd (pre-tax, marginal) ≈ 5.5% *(assumption — based on recent BBB-rated LVS issuance coupons 5.3–5.65% per cbonds.com/Public.com,
                                credit upgraded BBB- → BBB, ในบริบท hiking-cycle marginal cost)*
Kd (after-tax, assume 21% effective tax) = 4.35%

WACC (pure CAPM) = 62.89%×8.43% + 37.11%×4.35% = 6.91%
WACC (concentration-adjusted, +200bps สำหรับ idiosyncratic-risk ที่ concentrated portfolio ไม่ diversify ออกได้เต็มที่) = 8.91%
```
**Flag ให้ Charlie:** WACC จาก pure CAPM (6.91%) ต่ำผิดปกติสำหรับหุ้น gaming/EM-travel-exposed ที่มี net debt $11.9B ในช่วง hiking cycle — เกิดจาก beta ต่ำ (0.82) ที่ underrate total risk ตามที่อธิบายใน correlation section ด้านบน Quinn ใช้ **8.5–9.5% เป็น working WACC range** (ไม่ใช้ 6.91% ตรงๆ) สอดคล้องกับ Atlas's guidance range "mid-cap 10-13%" แต่ปรับลงเล็กน้อยเพราะ LVS market cap $25.9B ใหญ่กว่า mid-cap ทั่วไป

### 5. EBITDA Reconciliation (data gap fill — Atlas Section I flagged EBITDA absolute ไม่มีในpackage)
```
D&A TTM (approx) = 2 × H1 2026 D&A ($707M) = $1.414B  [Source: LVS 8-K/10-Q H1 2026, ycharts/SEC search retrieved this session]
                    *(approximation — assumes H2 ≈ H1, ไม่ใช่ true TTM จาก 4 ไตรมาสแยก)*
EBITDA TTM (GAAP-recon) = Op Income $3.19B + D&A $1.414B = $4.604B
EV (current) = Market Cap $25.895B + Net Debt $11.908B = $37.803B
EV/EBITDA (current, TTM) = $37.803B / $4.604B = 8.21x
```

### 6. Segment EBITDA Split (สำหรับ Sensitivity Matrix — replaces revenue-based proxy ด้วย actual property-level EBITDA)
```
H1 2026 Adjusted Property EBITDA:
  Macau      = Total consolidated ($1.42B Q1 + $1.12B Q2 = $2.54B) − MBS Singapore ($1.477B) = $1.063B
  Singapore (MBS) = $1.477B  [Source: LVS Q1/Q2 2026 earnings releases — prnewswire.com/Yogonet/AktienSensor]

Macau EBITDA share  = $1.063B / $2.54B = 41.9%
Singapore EBITDA share = $1.477B / $2.54B = 58.1%

*(Note: นี่คือ "Adjusted Property EBITDA" — non-GAAP, ไม่รวม corporate overhead/stock comp — ต่างจาก GAAP-recon EBITDA $4.604B ข้างต้น ใช้ % split เท่านั้นไม่ใช้ absolute figure)*

Macau EBITDA base (TTM, allocated)     = $4.604B × 41.9% = $1.927B
Singapore EBITDA base (TTM, allocated) = $4.604B × 58.1% = $2.677B
```
**Insight สำคัญ:** Singapore (MBS) มีสัดส่วน EBITDA มากกว่า Macau แล้วใน H1 2026 (58% vs 42%) — สวนทางกับสมมติฐาน default ที่หลายคนคิดว่า Macau ยังเป็นตัวหลัก สาเหตุคือ Macau Q2 2026 โดน VIP hold softness กระทบตรง (ตรงกับ "beaten-down reason: cyclical" ที่ Charlie ระบุ) ในขณะที่ Singapore margin แข็งแกร่งกว่า (53% margin Q1) — Singapore กลายเป็น **earnings anchor ที่ downside risk ต่ำกว่า** ส่วน Macau คือ recovery/optionality lever

## Probability-Weighted Expected Value (P-W EV)

| Scenario | Macau GGR | Singapore EBITDA Growth | Probability | FV/share |
|----------|-----------|--------------------------|--------------|----------|
| Bear | 0.0% | −10% (hold reversion persists + China slows) | 20% | $41.87 |
| Base-Bear | +2.5% | −5% | 20% | $44.40 |
| Base | +5.0% (consensus) | 0% (flat, normalized) | 30% | $46.93 |
| Base-Bull | +7.5% | +10% | 20% | $51.32 |
| Bull | +10.0% (World Cup 2026 resolves + hold reverts up) | +20% | 10% | $55.71 |

```
P-W EV = Σ(FV_i × Prob_i) = $47.17
```

**Quinn's Independent FV = $47.17** (multiple-based, at base 9.0x forward EV/EBITDA across all scenarios)
**MOS (at P-W EV) = ($47.17 − $39.98)/$47.17 = 15.24%**

⚠️ **นี่คือ MOS ที่ assume multiple re-rate กลับไป 9.0x — ถ้าใช้ multiple ปัจจุบัน 8.21x คงที่ทุก scenario แทน (conservative, no-rerating case) จะได้ P-W EV ต่ำลง และ MOS แคบลงมาก (ใกล้เคียง 0-5% เท่านั้น ตาม stress table ด้านบน)** Quinn รายงานทั้งสอง scenario ให้ Charlie ตัดสินใจว่าจะใช้ตัวไหนเป็น gate number

## Quinn's Conclusion

**Quinn's Independent FV (P-W EV): $47.17/share** (base case, multiple re-rating to 9.0x assumed)
**Alternative (no-rerating, multiple stays at current 8.21x): FV ≈ $41-42/share, MOS only ~0-5%**

**สัญญาณเชิงสถิติ:** Sharpe ratio ต่ำมากภายใต้ pure CAPM (0.14) เพราะ beta ต่ำ (0.82) กดเพดาน required-return ทั้งที่ total volatility จริงสูง (25.4%) — นี่คือหุ้นที่ CAPM underestimate ความเสี่ยงจริง เหมาะกับการ discount ผ่าน higher WACC (8.5-9.5%) มากกว่าเชื่อ pure-beta cost of equity Implied correlation กับ S&P 500 ต่ำ (~0.48) ยืนยันเชิงปริมาณว่า LVS มี diversification value ต่อพอร์ต US-cycle-heavy — จุดแข็งด้าน portfolio construction แม้ single-stock risk (China/Macau concentration) จะสูง
