## 5. Kelly Criterion + Position Sizing [CFA L3: Portfolio Construction — Kelly Criterion]

### Quarter-Kelly Calculation
- **Edge (p):** P(Bull+Base) = 65%, P(Bear+Extreme) = 35%
- **Win multiple (b):** Bull FV/Price = $168/$122.88 = 1.37 (37% upside)
- **Loss factor:** Bear FV/Price = $72/$122.88 = 0.586 (41.4% downside)

**Kelly Formula: f* = (b×p - q) / b**
- f* = (1.37 × 0.65 - 0.35) / 1.37
- f* = (0.891 - 0.35) / 1.37
- f* = 0.541 / 1.37
- **Full Kelly = 39.5%** — (ใหญ่เกินไป, ใช้ Quarter-Kelly)
- **Quarter-Kelly = ~9.9%** — ยังสูงมาก

**Practical Sizing:**
- Max portfolio concentration (House Rules): ไม่เกิน 5-7% per name (mature defensives ≤5%)
- **Recommended Position: 3–4%** (Quarter-Kelly capped + DOGE uncertainty discount)
