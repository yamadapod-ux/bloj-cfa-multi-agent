### 2.1 Cost of Equity / WACC — CAPM with Blume-adjusted beta

RDDT has negligible debt (Total Debt $20.87M vs Market Cap $30.42B, D/E ≈ 0.07%) → **WACC ≈ Cost of Equity**

```
Ke = Rf + β × ERP
Rf = 4.79% [Source: CNBC US10Y, Sept 2, 2026 — Atlas Data Package Section F]
ERP = 5.00% *(assumption — no independent equity-risk-premium source verified this session;
              consistent with Emma's 5.0-5.3% range to keep WACC comparable across analysts)*
β(spot, 5Y monthly) = 2.03 [Source: Yahoo Finance — Atlas Data Package Section A/F]
```

**Blume-adjusted beta** [CFA L2: Equity — Adjusted Beta technique]: `β_adj = 0.33 + 0.67 × β_raw = 0.33 + 0.67×2.03 = 1.69`
This is a statistical mean-reversion-toward-1.0 technique (Blume, 1975) — distinct from Emma's ad hoc "1.85 judgment overlay for S&P inclusion," but converges to a similar zone, which is a useful independent cross-check.
