> **Scope note:** งานนี้ใช้เฉพาะข้อมูลจาก Atlas Data Package (`agent_notes/atlas/2026-08-05_VRT_data.md`), Macro Brief (`2026-08-05_VRT.md`) และ Regime record (`2026-08-05_regime.md`) เท่านั้น — ไม่มีการ WebSearch เพิ่มเติมตามคำสั่งขอบเขตงาน ทุกตัวเลขที่ไม่ได้อยู่ใน package โดยตรง (เช่น ERP, probability weights, multiple compression scenarios) ถูก flag เป็น **assumption** อย่างชัดเจน แยกจาก sourced data

## Methodology

เนื่องจากไม่มี daily/monthly price return series ใน Atlas package (บล็อกไม่ให้ WebSearch เพิ่มสำหรับงานนี้) Quinn ปรับ methodology ให้ใช้ข้อมูลที่มีอยู่จริงเท่านั้น:

1. **Max Drawdown** — คำนวณตรงจาก 52W High/Low (exact, ไม่ใช่ estimate)
2. **Volatility** — ประมาณ 2 วิธี เพราะไม่มี actual return series:
   - Parkinson range-based estimator จาก 52W High/Low (สะท้อน total historical volatility)
   - Beta-implied systematic-only volatility (Beta × VIX) — VIX เป็น sourced data จาก Regime record
3. **Sharpe Ratio** — ใช้ **forward-looking** analyst-consensus-implied return (PT avg $337.50, sourced) แทน trailing realized return (ซึ่งไม่มีข้อมูลพอ) — นี่คือ proxy Sharpe ไม่ใช่ trailing/realized Sharpe ตามนิยามดั้งเดิม ต้อง caveat ชัดเจน
4. **Sortino** — **ไม่สามารถคำนวณได้อย่างมีนัยสำคัญ** เพราะต้องการ downside-only return series ซึ่งไม่มีในข้อมูล → mark N/A
5. **VaR/CVaR** — Parametric (normal-distribution) formula ใช้ volatility 2 แบบข้างต้น
6. **P-W EV** — 3-scenario (Bear/Base/Bull) บน FY26 guided revenue × EV/Revenue multiple ranges
7. **Growth MOS Gate** — Method 1 (Reverse DCF ผ่าน Gordon Growth model บน FCF) + Method 2 (Multiple Percentile — ไม่สามารถทำได้ ข้อมูล 5Y history ไม่มีใน package และ Atlas เองก็ flag ว่าหาไม่ได้ใน Section I)

### 2. Volatility Estimates [CFA L1: Statistical Concepts — Range-based estimators]
- Parkinson single-range estimator: σ = ln(High/Low) / (2×√ln2) = ln(379.94/118.70)/(2×0.8326) = **69.87% annualized**
  `[Source: 52W High/Low, Atlas Data Package Section A]` — สะท้อน total historical volatility (systematic + idiosyncratic) ตลอด 52 สัปดาห์ที่ผันผวนมาก รวมทั้งช่วง crash และ recovery
- Beta-implied systematic-only vol = Beta × VIX = 2.05 × 16.54% = **33.91% annualized**
  `[Source: Beta — Atlas Data Package Section F; VIX 16.54 — Atlas Regime record 2026-08-05]` — underestimate ความเสี่ยงจริงเพราะไม่รวม idiosyncratic risk (สมมติ ρ=1 กับตลาด)
- **Interpretation:** ค่าจริงน่าจะอยู่ระหว่างสองค่านี้ (~34–70%) — ทั้งสองวิธีชี้ตรงกันว่า VRT เป็นหุ้นความผันผวนสูงมาก

### 3. Sharpe Ratio (forward-looking proxy) [CFA L1: Portfolio Management — Risk-Adjusted Return]
- Analyst-consensus implied forward return = (PT avg $337.50 − Price $269.93)/$269.93 = **+25.03%**
  `[Source: Analyst Consensus PT, Atlas Data Package Section H]`
- Risk-free rate = 4.63% `[Source: 10Y Treasury, Atlas Data Package Section F]`
- **Sharpe (Parkinson vol 69.87%)** = (25.03%−4.63%)/69.87% = **0.292** — แย่ (ต่ำกว่า 1.0 มาก)
- **Sharpe (Beta-implied vol 33.91%)** = (25.03%−4.63%)/33.91% = **0.602** — พอใช้แต่ยังไม่ดี
- **⚠️ Caveat สำคัญ:** นี่คือ Sharpe แบบ forward-looking บน analyst consensus ไม่ใช่ trailing realized Sharpe (ต้องการ daily/monthly return series ที่ไม่มีในข้อมูล) — ตีความอย่างระมัดระวัง เป็น proxy เท่านั้น

### Method 1: Reverse DCF (Gordon Growth Model บน FCF)
Formula: MarketCap = FCF₀×(1+g)/(r−g) → solve for g

- Market Cap = $103.92B `[Source: Atlas Section A]`
- TTM FCF = $2.93B `[Source: Atlas Section D]`
- r (CAPM cost of equity) = 15.90% *(ใช้แทน WACC เพราะ VRT net cash position, ต้นทุนหนี้ต่ำ+leverage ต่ำมาก — cost of equity ≈ WACC โดยประมาณ)*

Solving: **g_implied = 12.73%** (perpetual/terminal growth rate ที่ราคาปัจจุบัน price-in)

- เทียบกับ FY26 guided organic growth midpoint 31% (range 30-32%) `[Source: Atlas Section H]`
- Ratio = 12.73%/31% = **0.41×** consensus (threshold: ≤1.2×)
- **ผลลัพธ์: PASS อย่างชัดเจน** (0.41× ต่ำกว่า threshold มาก)

**หมายเหตุตีความ:** ตัวเลข 12.73% เป็น *perpetual/terminal* growth rate ไม่ใช่ near-term growth rate — โดยธรรมชาติต้องต่ำกว่า near-term guided growth (30-32%) มากอยู่แล้วเพราะไม่มีบริษัทไหนโต 30%+ ตลอดไปได้ การที่ market ปัจจุบัน price-in เพียง 12.73% ตลอดชีพ (แทนที่จะ extrapolate 30%+ ไปเรื่อยๆ) สะท้อนว่าตลาด**ไม่ได้** price-in "perfect execution ตลอดกาล" — มี margin of safety เชิง terminal-value assumption

**Supplementary cross-check (ไม่ใช่ formal test แต่ flag ไว้):** PEG-implied consensus EPS growth = Forward P/E(36.5x)/PEG(0.91) = 40.11% → เทียบ guided revenue growth 31% = **1.29×** (เกิน 1.2× threshold ถ้าใช้เป็น test) — อย่างไรก็ตาม ตัวเลขนี้คือ **consensus EPS growth estimate ที่ใช้คำนวณ PEG อยู่แล้ว** (ไม่ใช่ตัวเลข reverse-engineer จากราคาอิสระ) และเป็น EPS basis ไม่ใช่ Revenue basis (อาจสูงกว่าเพราะ operating leverage/margin expansion) — ไม่ใช้เป็น formal Method 1 เพราะ methodology ไม่ตรงกับ "reverse DCF" ตามนิยาม CFA — แต่ flag ไว้เป็นสัญญาณเตือนว่า EPS growth expectation ฝังอยู่ในราคาสูงกว่า revenue growth guide พอสมควร ควร monitor margin trajectory
