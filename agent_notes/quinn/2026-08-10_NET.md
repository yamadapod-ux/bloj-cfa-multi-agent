### 8. Risk Metrics

**Volatility estimate (assumption — ไม่มี historical daily price series ใน session นี้):**
```
σ_market (proxy) = VIX close 2026-08-07 = 14.90%  [Source: agent_notes/atlas/2026-08-10_regime.md — Yahoo Finance ^VIX]
σ_systematic = β × σ_market = 1.66 × 14.9% = 24.73%  <- lower bound, ignore idiosyncratic risk
R² assumed = 28% *(assumption — typical single-stock R² vs S&P 500 for high-idiosyncratic-risk growth names, 20-35% range)*
σ_total = σ_systematic / √R² = 24.73% / √0.28 = 46.74%
```
*(Limitation: ไม่ใช่ empirical historical volatility — เป็น model-based estimate จาก beta + assumed R². Flag ความเชื่อมั่นต่ำ)*

```
Forward Sharpe  = (E(R)_CAPM − Rf) / σ_total = (11.69% − 4.67%) / 46.74% = 0.150
Forward Sortino = (E(R)_CAPM − Rf) / σ_downside ; σ_downside = σ_total × 1.10 *(assumption — richly-valued growth names skew negative-tail heavier)*
                = 7.02% / 51.41% = 0.137
```
Sharpe 0.15 < 1.0 (พอใช้ threshold) — **ต่ำกว่าเกณฑ์มาก** ใกล้เคียงกับ AVGO (0.12), QCOM (0.18) ในพอร์ต ไม่ใช่ WPM (-0.17 ติดลบ) แต่ก็ไม่ใช่ระดับที่ดี

**Parametric VaR/CVaR (1-day, 95%):**
```
σ_daily = 46.74%/√252 = 2.944%
μ_daily = 11.69%/252 = 0.0464%
VaR95(1-day) = μ_daily − 1.645×σ_daily = -4.80%
CVaR95(1-day) = μ_daily − σ_daily×[φ(1.645)/0.05] = -6.03%
```
[CFA L1: Quantitative Methods — Value at Risk / Expected Shortfall]
