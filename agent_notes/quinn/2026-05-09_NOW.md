### Kelly Criterion [CFA L3: Portfolio Management — Kelly Criterion]

- p (win probability: Bull + Base) = 65%
- b (win/loss ratio): Avg win = ($148-$91)/$91 = 62.6%, Avg loss = ($91-$75)/$91 = 17.6%
- b = 62.6% / 17.6% = 3.56
- Kelly = p - (1-p)/b = 0.65 - (0.35/3.56) = 0.65 - 0.098 = **0.552 = 55%** (Kelly full)
- **Quarter-Kelly = 13.8%** → cap at **5%** (portfolio concentration check)

**Position Sizing Rationale:**
- Quarter-Kelly = 13.8% → too high for elevated volatility name
- Apply "elevated drawdown haircut" (50% further cut) → 6.9%
- Round down to 5% for portfolio management (Technology bucket near ceiling)
- Staged across 3 tranches: 2% + 2% + 1% = 5%

## Hypothesis Testing — Outperformance [CFA L1: Statistical Analysis — Hypothesis Testing]

H₀: NOW expected return = market (S&P 500)
H₁: NOW expected return > market (one-tailed)

- Test Statistic: t = (forward return - market return) / (vol / √n)
- Estimated: t = (17.7% - 8.5%) / (35% / √3) = 9.2% / 20.2% = **0.455**
- **Fail to reject H₀ at α=0.05** (critical value ~1.65 for one-tailed)
- Interpretation: Quant cannot statistically confirm outperformance with confidence — this is a fundamental-driven investment, not statistically-confirmed quant signal

**This is why Quinn conviction = 6/10 not higher** — quant cannot reject H₀; investment relies on Emma's fundamental thesis being correct
