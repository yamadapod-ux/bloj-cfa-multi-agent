## 4. Kelly Criterion
[CFA L3: Portfolio Management — Kelly Criterion, Position Sizing]

From the §2 scenario tree:
```
p (win: Base+Bull)  = 0.72        avg win  = (0.47×+17% + 0.25×+71%)/0.72 = +35.7%
q (loss: Bear)      = 0.28        loss     = −43.7%
b (odds)            = 0.357 / 0.437 = 0.817
Full Kelly f* = (b·p − q)/b = (0.817×0.72 − 0.28)/0.817 = 0.303/0.817 = 0.371  → 37%
Half Kelly ≈ 18.5%   |   Quarter Kelly ≈ 9.3%
```

**Continuous cross-check** (f* ≈ μ_excess / σ²):
- Point-estimate basis: μ_excess ≈ 3.4%/yr (MOS 12.7% over ~3yr + ~3% growth − Rf 3.85%), σ 38% → f* = 0.034/0.144 = **0.24 → quarter ≈ 6%**
- **Scenario-annualized basis** (captures leveraged bear tail): P-W annual return ≈ **+1.7%/yr** (§5) → μ_excess ≈ **−2.2%/yr → NEGATIVE Kelly**

### Verdict: **edge is marginally positive on the point estimate, ~zero-to-negative once the leveraged downside is annualized.**
Kelly is inflated by the fat bull tail (+71%) and the binary framing. **No clean Kelly-justified position.** If a position were forced despite the sub-gate MOS: quarter-Kelly with tail haircut → **~3% (house floor)** — but the disciplined output is **WAIT / no deploy**.

## 5. Forward Sharpe (from $47.95)
[CFA L1: Portfolio Management — Sharpe Ratio]

P-W annualized total return (4-yr convergence horizon, no dividend):
```
Bear  $27 : (27/47.95)^0.25 − 1   = −13.4%/yr   × 0.28 = −3.75
Base  $56 : (56/47.95)^0.25 − 1   =  +3.98%/yr  × 0.47 = +1.87
Bull  $82 : (82/47.95)^0.25 − 1   = +14.4%/yr   × 0.25 = +3.60
P-W annual return ≈ +1.72%/yr
```
```
Forward Sharpe = (E[R] − Rf) / σ_fwd = (1.72% − 3.85%) / 38% = −0.056  ≈  −0.06
```
Point-estimate approach (ignoring tail): ≈ **+0.09**. Either way **far below the S&P 500 benchmark 0.55.**

### Forward Sharpe ≈ −0.06 → **PRIMARY QUANT SIGNAL AGAINST deploying at $47.95.**
The negative forward Sharpe is structural: a leveraged cyclical at trough multiples has a fat left tail relative to a modest base case. This does **not** mean "bad company" — it means "not a compelling risk-adjusted entry at this price." Forward Sharpe turns positive (~+0.25) around **$40–42**, where base-case MOS exceeds ~30% and the bear downside compresses.
