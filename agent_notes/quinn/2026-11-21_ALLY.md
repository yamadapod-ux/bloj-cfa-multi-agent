## Methodology
- **Residual Income (RI) model บน common equity** [CFA L2: Equity Valuation — Residual Income Model]: V0 = BV0 + Σ (ROE_t − CoE)·BV_{t−1}/(1+CoE)^t + TV, forecast 10 ปี (ตรง pre-registration "10 ปี + fade") แล้ว residual income ปีที่ 11+ decay ด้วย persistence ω = 0.5 (TV = RI₁₁/(1+CoE−ω))  [CFA L2: RI — Persistence Factor] *(ยังไม่เรียน — ω คืออัตราที่ excess return ยังคงอยู่ปีถัดไป, 1 = ถาวร, 0 = หายทันที)*
- **Terminal RONIC:** การเติบโตของ book หลังปีที่ 10 ถือว่าให้ผลตอบแทน = CoE (ไม่สร้างมูลค่าเพิ่ม); มีเพียง excess return ของ book เดิมที่ decay 50%/ปี. สอดคล้องกับ VS2 1.3 (ไม่โตฟรี)
