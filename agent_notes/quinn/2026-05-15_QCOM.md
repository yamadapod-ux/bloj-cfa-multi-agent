### VaR / CVaR / Max Drawdown [CFA L3: Portfolio — Tail Risk]

**VaR (Parametric, 95% confidence, 1-month):**
```
VaR = μ − 1.645 × σ
Monthly return ≈ 0%  (at FV ≈ price)
Monthly σ ≈ 37.5% / √12 = 10.8%
VaR(95%, 1M) = 0% − 1.645 × 10.8% = -17.8%
```
→ 5% chance of losing more than 17.8% in any single month

**CVaR / Expected Shortfall (95%):**
```
CVaR = VaR × φ(z) / (1 − c)
≈ -17.8% × 1.3 ≈ -23%
```
→ Expected loss given we're in the worst 5% = -23%

**Max Drawdown (Historical):**
- Peak (2021 high ~$200) → Trough (~$110 in 2023) = -45% [Source: Atlas historical estimate]
- Current drawdown from ATH $247: (~$218 - $247) / $247 ≈ -12% [Source: Atlas]
- **Max Drawdown estimate: -45%** — significant tail risk for large-cap semi

**China Binary Scenario VaR:**
- If China export restrictions hit suddenly: QCOM revenue -30% = EPS -35% = implied price drop -40% to -50% from current = **Black Swan VaR: -40%**

### Kelly Criterion [CFA L3: Portfolio Construction — Kelly]

**Setup:**
- Win probability (p): 55% (base + bull probability = 55+25 = 80%? But adjusted for MOS ≈ 0% = lower win probability)
  - Actually: P(price above $218 in 12M) = depends on scenario
  - Bull (25%): reach $284 = +30% ✓
  - Base (55%): reach $217 = flat ≈ 0% break-even ✗ (insufficient return)
  - Bear (20%): reach $136 = -38% ✗

**Revised for CAPM (required return 11.10%):**
- P(exceed required return of 11.10%): Only Bull case (~25%) strongly exceeds; Base barely achieves dividend
- Win: p = 30% (adjusted for required return threshold)
- Win amount (b): +30% (bull case upside)
- Loss amount (q): -38% (bear case drawdown)

```
Kelly fraction = (p × b − (1-p)) / b
= (0.30 × 0.30 − 0.70) / 0.30
= (0.09 − 0.70) / 0.30
= -0.61 / 0.30
= -2.03 → NEGATIVE

Quarter-Kelly = -0.5 → Kelly says NO BUY at $218
```

**Kelly Interpretation:** At $218 (≈ base FV), Kelly is negative → insufficient expected return to justify position. Kelly turns positive at ~$185-$195 (entry zone).

### Hypothesis Testing — Excess Return [CFA L1: Quantitative — Hypothesis Testing]

```
H₀: QCOM expected return = Market (S&P 500) expected return
H₁: QCOM expected return > Market expected return

Test statistic: Using 3Y annualized alpha (est. +3.5-5.0%/yr)
Standard Error: σ_alpha / √n = (37.5% / √36 months) = 6.25%
t-statistic: 4.25% / 6.25% = 0.68

p-value ≈ 0.25 (single-tail)
```

**Result: Fail to reject H₀ at α=0.05** — Evidence of excess return is not statistically significant. Alpha is marginally present but unreliable.
