## Kelly Criterion Calculation

**Quarter-Kelly Position Size:**
- P-W EV = $141.90
- Current Price = $116
- Edge = (141.90 - 116) / 116 = **22.3%**
- Win probability estimate (Base+Bull scenarios): 65%
