## 5. Kelly Criterion — Position Sizing [CFA L3: Portfolio Construction — Kelly Criterion]

### Kelly Formula
Kelly % = (p × b – q) / b
โดยที่: p = probability of win, q = 1-p, b = win/loss ratio

**สำหรับ TMDX:**
- Bull scenario (P-W คาด): $55 → upside จาก $40 = +37.5% | probability: 20%
- Base scenario: $24 → downside = -40% | probability: 45%
- Bear scenario: $12 → downside = -70% | probability: 25%
- Extreme scenario: $5 → downside = -87.5% | probability: 10%

**Expected Value Calculation:**
P-W EV = (0.20 × $55) + (0.45 × $24) + (0.25 × $12) + (0.10 × $5)
= $11.00 + $10.80 + $3.00 + $0.50
= **$25.30**

P-W EV vs Current Price: $25.30 / $40 = **-36.8% expected return** (Negative Expected Value)

**Kelly Criterion Result:**
เมื่อ Expected Value เป็นลบ (EV < current price) → Kelly fraction = **0% (ไม่ควรถือ)**

**Half-Kelly (Conservative):** ยืนยัน 0% — ไม่มี position ที่สมเหตุสมผลที่ราคา $40

**Quinn's Conclusion:**
ที่ราคา $40 TMDX มี negative expected return (-36.8%) ตาม probability-weighted scenario analysis Kelly Criterion แนะนำ 0% position การที่ตลาดยังให้ราคา $40 สะท้อน narrative bias (organ tech disruption story) มากกว่า fundamental value
