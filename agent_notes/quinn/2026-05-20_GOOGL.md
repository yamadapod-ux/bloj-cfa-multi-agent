### Kelly Criterion [CFA L3: Portfolio Management — Position Sizing]

```
Kelly Formula (simplified for single-asset): K = (p × b - q) / b
Where:
  p = probability of winning = 75% (Bull + Base)
  q = probability of losing = 25% (Bear + Extreme Bear)
  b = ratio of gain to loss = ($177.25 / $170 - 1) / (downside %)
  
Downside estimate: Bear weighted avg = ($125×20% + $75×5%) / 25% = ($25+$3.75)/25% = $115
Loss ratio: ($170 - $115) / $170 = 32.4%
Gain ratio: ($177.25 - $170) / $170 = 4.3%

Kelly = (0.75 × 4.3% - 0.25 × 32.4%) / 4.3%
      = (3.23% - 8.1%) / 4.3%
      = -4.87% / 4.3% = -1.13 ← NEGATIVE Kelly

Quarter-Kelly = NEGATIVE → quant signal: ไม่ deploy ณ $170 (base case FV ~$177)
```

*ผล Kelly NEGATIVE เพราะ asymmetry: downside (DOJ extreme: -56%) > upside (base: +4.3%)*
*ถ้าใช้ Bull case FV $220: Kelly = (0.75×29.4% - 0.25×32.4%) / 29.4% = (22.1% - 8.1%) / 29.4% = **+47.6%** → Quarter-Kelly = **12%** (capped at IPS max 10%)*

**ข้อสรุป Kelly:** สัญญาณ deploy ขึ้นอยู่กับ probability ที่ถูก assign ให้ Bull case มากแค่ไหน
