### 4. Kelly Criterion [CFA L3: Portfolio Construction — Kelly Criterion]

**Kelly Formula:** f* = (p × b - q) / b
- p = probability of win = 55% (Bull or Base scenario)
- q = 1 - p = 45%
- b = odds = Upside/Downside ratio

**ถ้าราคา $440 และ FV $260 (Emma):**
- Downside = ($440 - $150 Bear) / $440 = 66%
- Upside = ($440 → target $340 Bull) = -23% (ราคาปัจจุบันสูงกว่า FV → Kelly negative)

**Kelly Signal: NEGATIVE** (เมื่อ current price > blended FV → Kelly < 0 → อย่าเข้าตอนนี้)

*Note: ถ้าราคา pullback ลงมา $360-380 (เท่ากับ FV ± 5%):*
- Upside = $450 (Bull) / $360 = +25%
- Downside = $260 / $360 = -28%
- p = 55%, q = 45%, b = 25/28 = 0.89
- Kelly = (0.55 × 0.89 - 0.45) / 0.89 = (0.49 - 0.45) / 0.89 = 0.04 / 0.89 = **4.5%**
- Quarter-Kelly = **~1.1%** (small due to uncertainty)

**Quinn Position Sizing Recommendation: 0% (AVOID) ณ ราคา > $400 | Quarter-Kelly ~1-2% ถ้าราคา $360-380**
