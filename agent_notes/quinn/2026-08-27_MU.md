# Quinn's Notes — MU (2026-08-27)

## Methodology

MU (Micron Technology) เป็น **Growth bucket, semiconductor memory cyclical** — ตัว Beta 2.21 สูงที่สุดในพอร์ตที่เคยวิเคราะห์ (สูงกว่า RKLB 2.10 ซึ่งเคยเป็นสถิติสูงสุด) ผสมกับ commodity-cycle business ที่มี historical downcycle รุนแรง (FY2023 revenue -49%) — ตาม Atlas flag ใน Data Package Section F ให้ Quinn รัน sensitivity ครอบคลุมทั้ง memory-ASP/pricing assumption และ margin cycle พร้อมกัน (compound risk)

Framework ที่เลือกใช้:
1. **CAPM-based forward Sharpe** — ใช้ Beta 2.21 (verified) + Risk-free rate + Equity Risk Premium (WebSearch เพิ่มเติมตามที่ Atlas Data Package Section F ระบุว่า "Quinn ควร WebSearch 10Y level ตรงเพิ่มถ้าต้องการ exact WACC input") — คำนวณ expected return ตาม CAPM แล้วหารด้วย volatility proxy
2. **Volatility estimation — ไม่มี daily/monthly price series ใน Data Package** จึงใช้ 3 วิธี cross-validate: (a) Beta×VIX (ρ=1 lower bound), (b) Beta×VIX/ρ=0.6 (moderate correlation), (c) Parkinson 52W High-Low range estimator, (d) **verified market-implied volatility จาก options chain (WebSearch เพิ่มเติม, มี URL)** — ใช้ (d) เป็นค่าหลักเพราะเป็น empirical market-priced vol ไม่ใช่ proxy
3. **Scenario-based Probability-Weighted EV** — Bull/Base/Bear ผูกกับ Sensitivity Matrix (Revenue Growth × Operating Margin) โดยให้น้ำหนัก Bear scenario สะท้อน historical -49% revenue downcycle precedent อย่างจริงจัง (30% ไม่ใช่ tail case เบาๆ) ตามคำสั่งงาน
4. **Sensitivity Matrix** — ใช้ P/E TTM 21x (sourced, Data Package Section A) เป็น anchor multiple คงที่ตลอด grid, แปลง Operating Margin → Net Margin ด้วย conversion ratio ที่ calibrate จาก TTM actual (NI margin/OM = 55.91%/65.67% = 0.8514) เพื่อไม่ fabricate tax-rate assumption แยก
5. **Kelly Criterion** — derive จาก win/loss classification ของ scenario framework เดียวกัน (ไม่ใช่ตัวเลขลอย)

### H. Kelly Criterion
```
P(win) = P(Bull) + P(Base ที่ผลตอบแทนบวก)... 
```
ตรวจสอบ: Base scenario ให้ return -6.6% (ติดลบ) ดังนั้น classify เป็น "loss" → Win = Bull only (25%), Loss = Base+Bear (75%)

```
P(win) = 25%, P(loss) = 75%
Avg win magnitude = 53.3%
Avg loss magnitude (prob-weighted) = 37.6%
Odds b = avg_win / avg_loss = 53.3% / 37.6% = 1.419

Kelly f* = (p×b - q) / b = (0.25×1.419 - 0.75) / 1.419 = -27.9%
Half-Kelly = -13.9%
Quarter-Kelly = -7.0%
```
[CFA L3: Portfolio Management — Kelly Criterion / Optimal Position Sizing]

**ผลลัพธ์ Kelly ติดลบ** = สัญญาณ "ไม่ควรถือ long position เพิ่ม" จากมุมมอง quant pure-play — สอดคล้องกับ P-W EV ติดลบ (-14.85%) และ scenario-based Sharpe/Sortino ติดลบทั้งคู่ — **ทั้ง 3 metric ชี้ทิศทางเดียวกัน** (internal consistency check ผ่าน)
