### 6. Kelly Criterion [CFA L3: Position Sizing]

**⚠️ ใช้ข้อมูลจาก WACC×TGR sensitivity matrix (upside fraction) — flag ชัดเจนว่า output inflated จาก terminal-value dominance เดียวกันกับที่พบใน matrix (ดู Sensitivity Matrix section) — ไม่ควรใช้ Kelly output นี้กำหนด position size โดยตรง**

```
p (win probability, upside cells) = 24/25 = 96%
q = 4%
b (edge) = P-W EV/Price - 1 = $370.75/$243.00 - 1 = 0.526

f* = (b×p - q) / b = (0.526×0.96 - 0.04) / 0.526 = 0.465/0.526 = 88.4%
Quarter-Kelly = 22.1%
Half-Kelly = 44.2%
```

**Kelly output นี้ไม่สมเหตุสมผลในทางปฏิบัติ** — Full Kelly 88.4% และแม้ Quarter-Kelly 22.1% ก็เกิน IPS single-position cap (8-10%) ไปมาก เพราะ p=96% มาจาก sensitivity matrix ที่มี upside cell เกือบทุกช่อง (terminal-value dominance artifact จาก WACC-TGR spread แคบ ไม่ใช่สัญญาณว่าหุ้นนี้ risk-free) — **ผลสรุปเชิงปฏิบัติ: IPS hard cap 8-10% เป็นตัวกำหนด position size ไม่ใช่ Kelly ในกรณีนี้** ตำแหน่งปัจจุบัน weight ~7.26% อยู่ในกรอบ IPS อยู่แล้ว ไม่มีเหตุผลเชิงปริมาณให้เพิ่ม/ลดจาก Kelly signal ที่ inflate เกินจริง
