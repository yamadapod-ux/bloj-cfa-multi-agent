## 2. PROBABILITY-WEIGHTED EXPECTED VALUE (P-W EV) [CFA L3: Scenario Analysis] *(ยังไม่เรียน — P-W EV = weighted average of scenario values by their probabilities)*

| Bull | +60% | 60% | 70x | ~$900 |

### 2C. Probability-Weighted EV

P-W EV = (0.25 × $180) + (0.45 × $580) + (0.25 × $900) + (0.05 × $50)

= $45 + $261 + $225 + $2.50

= **$533.50**

**Quinn P-W EV: ~$534**

*Interpretation: At $501, P-W EV $534 = +6.6% upside. Risk/reward slightly favorable but NOT compelling given 60% annualized volatility.*

### 2D. Kelly Criterion [CFA L3: Portfolio Sizing]

**Kelly Formula:** K = (bp - q) / b

Where:
- b = upside-to-downside ratio
- Upside (Bull): ($534 P-W EV / $501 - 1) = +6.6%
- Downside (Bear 25% scenario): ($180 / $501 - 1) = -64%
- p (probability of gain): 70% (Bear 25% + Black Swan 5% = 30% prob of losing)
- q = 0.30

**Kelly Calculation:**
- b = 6.6% / 64% = 0.103 (low!)
- K = (0.103 × 0.70 - 0.30) / 0.103 = (0.072 - 0.30) / 0.103 = -0.228 / 0.103 = **-2.21 (NEGATIVE)**

**Kelly is NEGATIVE at $501.** This signals the risk/reward is unfavorable at current price.

**Quarter-Kelly:** N/A (Kelly negative → position size = 0%)

*BUT: Kelly formula is extremely sensitive to scenario probabilities. If we raise Bull probability to 35% (at expense of Bear 20%):*
*K = (0.103 × 0.80 - 0.20) / 0.103 = (0.082 - 0.20) / 0.103 = -1.15 → still negative*

*Kelly turns positive only if P-W EV > $501 by meaningful margin AND downside significantly narrows.*
