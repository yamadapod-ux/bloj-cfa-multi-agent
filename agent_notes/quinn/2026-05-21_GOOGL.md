## 3. Kelly Criterion [CFA L3: Position Sizing]

**Kelly ณ $388:**
```
b (upside to Emma FV $425) = ($425/$388 - 1) = 9.5%
p (Bull + Base probability) = 25% + 55% = 80%
q = 1 - p = 20%

K = (b×p - q) / b
  = (9.5% × 80% - 20%) / 9.5%
  = (7.6% - 20%) / 9.5%
  = -12.4% / 9.5%
  = NEGATIVE (-1.31)
```

**Kelly NEGATIVE ณ $388** → position sizing ตาม Kelly = 0%; ไม่แนะนำ full deploy

**Kelly ณ entry zone $330:**
