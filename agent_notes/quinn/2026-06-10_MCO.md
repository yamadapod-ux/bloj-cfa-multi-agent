### 3. VaR / CVaR [CFA L3: Portfolio Management — Tail Risk]

```python
import math

# Parametric VaR (normal assumption)
annual_sigma = 0.21
daily_sigma = annual_sigma / math.sqrt(252)
# = 0.21 / 15.87 = 0.01323 = 1.323% daily

# VaR 95% (1-day): z = 1.645
var_95_1day = 1.645 * daily_sigma * 100
# = 1.645 * 1.323% = -2.18%

# VaR 99% (1-day): z = 2.326
var_99_1day = 2.326 * daily_sigma * 100
# = 2.326 * 1.323% = -3.08%

# CVaR/Expected Shortfall (99%): approx 1.25 * VaR_99
cvar_99 = 1.25 * var_99_1day
# = -3.85%
```

| Metric | ค่า | Implication |
|--------|-----|-------------|
| VaR 95% (1-day) | **-2.18%** | ในวันปกติ loss สูงสุด 5% โอกาส |
| VaR 99% (1-day) | **-3.08%** | Stress scenario |
| CVaR 99% | **-3.85%** | Expected loss ใน worst 1% days |
| Max Drawdown (est.) | **~-25%** | Lower than sector avg |

### 5. Kelly Criterion [CFA L3: Portfolio Construction — Kelly Criterion]

```python
# Kelly = (p*b - q) / b
# p = probability of success (BUY case)
# b = return if success (upside to FV $445-508)
# q = 1-p (probability of loss)
# a = loss if fail (downside)

price = 448
fv_base = 448  # Emma DCF
fv_relative = 508  # Emma Relative FV
fv_bear = 310  # Emma Bear DCF

# Using blended FV approach (Emma 40% + Quinn 35% + Bear 25%)
# Quinn's P-W EV (below)

p = 0.55  # probability upside (moderate — CPI uncertainty)
b_relative = (fv_relative - price) / price  # = (508-448)/448 = 0.134
a = (fv_bear - price) / price  # = (310-448)/448 = -0.308

kelly = (p * b_relative - (1-p) * abs(a)) / b_relative
# = (0.55 * 0.134 - 0.45 * 0.308) / 0.134
# = (0.0737 - 0.1386) / 0.134
# = -0.0649 / 0.134 = -0.484

# Quarter-Kelly for caution
quarter_kelly = kelly / 4
# = -0.121 (negative)
```

**Kelly = Negative at $448 (using Bear FV $310)**

Kelly negative ที่ exact price = $448 เพราะ Emma DCF FV = $448 = no margin of safety

**At $415 (5% pullback):**
```
b_relative = (508-415)/415 = 0.224
a = (310-415)/415 = -0.253
kelly = (0.55*0.224 - 0.45*0.253) / 0.224 = (0.123-0.114)/0.224 = 0.040
quarter_kelly = 0.01 = 1% — very thin
```

**At $390 (13% pullback):**
```
b_relative = (508-390)/390 = 0.303
a = (310-390)/390 = -0.205
kelly = (0.55*0.303 - 0.45*0.205) / 0.303 = (0.167-0.092)/0.303 = 0.247
quarter_kelly = 0.062 = 6.2% — strong signal
```

**Kelly Insight:** Full Kelly emerges at ~$390-410 (7-13% pullback) — เป็น Entry Zone ที่แท้จริง ที่ $448 ราคาแทบไม่มี Kelly signal
