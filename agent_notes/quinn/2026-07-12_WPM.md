## Methodology

WPM เป็น **precious-metals streaming** — revenue = ฟังก์ชันตรงของ gold + silver spot × production (GEOs) ด้วยต้นทุนคงที่ต่อออนซ์ (gold ~$425/oz, silver ~$4.5/oz). ดังนั้น **dominant risk factor คือ metal price ไม่ใช่ business-quality** เหมือนหุ้น tech/growth ปกติ กรอบที่เลือกใช้:

1. **Streaming Earnings Model** — bottom-up จาก physical production × (metal price − fixed cost) calibrate กับ TTM actuals → flex metal prices ใน 5×5 matrix
2. **Sensitivity Matrix = Gold × Silver** (ไม่ใช่ Gold × WACC) — เพราะ WPM มี 2 metal exposures (gold 55% / silver 45% Q1'26) และ silver rally (+65% YoY) เป็น swing factor สำคัญ ตลาดเถียงกันเรื่อง sustainability ของทั้งสองราคา ไม่ใช่ discount rate
3. **Probability-Weighted EV** — 3-scenario tree โดย **Bear = metal mean-reversion** (ปัจจัยเสี่ยงหลักตาม Atlas)
4. **Kelly + Forward Sharpe** — position sizing signal ที่ $110.05
5. **Commodity-beta vs genuine-alpha decomposition** — แยกว่า return ที่ผ่านมาคือ gold beta หรือ manager skill (critical สำหรับ conviction)

**Limitation สำคัญ (แจ้งก่อน):** ไม่มี daily/monthly return series verified ใน session นี้ → Sharpe/Sortino/vol เป็น **estimate** จาก 52W range (Parkinson proxy) + adopted vol assumption 37% ไม่ใช่ค่าคำนวณจาก raw returns. ## 2. Factor Model / Alpha Decomposition [CFA L2: Portfolio Mgmt — Multifactor Models]
*(Carhart 4-factor regression ไม่รันจริง — factor return series ไม่ verified ใน session นี้ → decompose เชิงโครงสร้างแทน)*

**Genuine idiosyncratic alpha ของ WPM ≈ ต่ำ. return ส่วนใหญ่ = gold/silver commodity beta.**

การแยกแยะ (critical สำหรับ conclusion):
- **Commodity beta (dominant):** WPM 1Y +23.87% ขับเคลื่อนโดย gold +~25% YoY + silver +65% YoY (metal mix ~55/45). WPM จริง ๆ **underperform** blended metal return (~+41%) เพราะ multiple compression + Constancia/Pampacancha depletion headwind → พิสูจน์ว่า price driver = metal ไม่ใช่ business execution.
- **Structural alpha vs operating miners (real แต่จำกัด):** fixed-cost model = 85.8% gross margin, ไม่มี capex/opex inflation risk, optionality บน reserve expansion ฟรี → นี่คือ genuine edge **เทียบกับ miners** แต่ **ไม่ใช่ alpha เทียบกับการถือ gold/silver โดยตรง** — เป็น leveraged beta ที่มี downside protection บางส่วน
- **CAPM E[R] (systematic only):** 4.49% + 1.19×(9%−4.49%) = **9.9%** — แต่ตัวเลขนี้ **ไร้ความหมาย** สำหรับ WPM เพราะ CAPM จับแค่ market beta ไม่จับ gold factor ที่เป็น 70–80% ของ variance

> **สรุป factor:** อย่าตีความ track record ของ WPM ว่าเป็น manager skill — มันคือ **leveraged bet บนทิศทางราคาโลหะ** ที่ไม่มีใคร forecast ได้แม่นยำ. Conviction ในหุ้นนี้ = conviction ในทิศทาง gold/silver 3–5 ปี ไม่ใช่ conviction ในบริษัท. [CFA L2: Factor Models — R² attribution]
