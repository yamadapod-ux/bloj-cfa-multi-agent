# Quinn's Notes — NOW (2026-05-11)

## Methodology

Framework ที่เลือกใช้สำหรับ ServiceNow:
1. **CAPM + Beta** — systematic risk measurement
2. **Carhart 4-Factor Model** — alpha estimation (เพิ่ม Momentum factor เพราะ NOW ลง 51% = anti-momentum ชัดเจน)
3. **Sharpe / Sortino / Treynor** — risk-adjusted return metrics
4. **VaR Parametric + CVaR** — tail risk quantification
5. **Sensitivity Matrix 5×5 (Revenue CAGR × WACC)** — fair value range ทุก scenario
6. **Probability-Weighted EV** — scenario-weighted fair value
7. **Kelly Criterion** — optimal position sizing

เลือก Revenue CAGR × WACC เป็น 2 ตัวแปรสำคัญสุดเพราะ:
- NOW is a growth story — CAGR deceleration คือ single biggest risk ที่ตลาดเถียงกัน
- WACC ขึ้นลงตาม rate environment และ beta ที่เปลี่ยนได้

### Kelly Criterion [CFA L3: Portfolio Construction — Kelly Criterion]

p = 0.65 (prob positive outcome — 25/25 sensitivity cells + moat quality)
b = upside multiple = $229 / $91 = 2.52x (using Quinn P-W EV)
q = 0.35
Kelly = (p × b - q) / b = (0.65 × 2.52 - 0.35) / 2.52 = (1.638 - 0.35) / 2.52 = 1.288/2.52 = 0.511 = 51%
**Quarter-Kelly = 12.8%**

Cap at 5%: portfolio concentration rule + first pure SaaS/workflow name + software sector ceiling (ไม่ได้ set explicitly แต่ conservative sizing appropriate)
