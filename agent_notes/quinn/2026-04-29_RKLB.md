## 6. Kelly Criterion [CFA L3: Position Sizing]

### Inputs
- Win prob (Neutron success → re-rate): 55%
- Win payoff (avg): +75% (to $43)
- Loss prob: 45%
- Loss payoff (avg): -45% (to $13.5)

### Calculation
- Edge = 0.55 × 75 + 0.45 × (-45) = +20.9%
- Kelly = Edge / Variance = 20.9% / [(0.55×0.75² + 0.45×0.45² – 0.209²)] = 20.9% / 39.7% = **52.6% (raw)**
- Half-Kelly = **26%**
- **Tail-corrected Kelly (high vol of vol + binary risk) = quarter-Kelly = 13%**
- **Practical max position: 4% (further reduced for portfolio concentration limits)**
