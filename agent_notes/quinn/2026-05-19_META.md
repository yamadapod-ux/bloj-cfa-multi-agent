### B. Risk Metrics [CFA L2: Portfolio Management — Risk Analytics]

**Beta Analysis:**
- Beta 1.25 (5Y estimate) = moderate-to-high systematic risk
- META มี beta ที่ลดลงจาก 2022 peak (~1.5+) เพราะ business fundamentals ดีขึ้นมาก
- ใน TRANSITIONAL-CAUTIOUS regime: Beta 1.25 หมายความว่า ถ้า S&P 500 ลง -10%, META คาดว่าลง ~-12.5%

**Historical Volatility (Estimated):**
- 3Y Annualized Volatility (σ): ~28-32% (Tech large-cap range)
- META เคย volatile มากใน 2022 (σ ~45%) แต่ stabilized

**Sharpe Ratio Calculation (Forward-Looking):**
```
Forward Sharpe = (Expected Return - Rf) / σ
= (11.0% - 4.5%) / 30% (midpoint estimate)
= 6.5% / 30%
= 0.217
```

*เปรียบเทียบ S&P 500 Forward Sharpe ≈ 0.45-0.55*

**Forward Sharpe: 0.217 — ต่ำกว่า S&P 500 Benchmark**

*หมายเหตุ: Forward Sharpe ต่ำ เพราะ CAPM E(R) 11% ไม่ capture upside จาก AI monetization inflection ถ้า thesis ถูก actual return อาจ 25-35% → Forward Sharpe 0.7+ ซึ่งสูงกว่า S&P 500*

**Sortino Ratio (Estimated):**
```
Sortino = (E(R) - Rf) / σ_downside
= 6.5% / 20% (downside σ ≈ 65-70% ของ total σ)
= 0.325
```

**Max Drawdown Historical:**
- 2022 Bear Market: META ลดจาก peak ~$385 ไปที่ ~$88 = **-77% Max Drawdown**
- Recovery: $88 (Nov 2022) → $611 (2026) = +594% (extraordinary recovery)
- 3Y Max Drawdown เชิงสถิติปัจจุบัน (ณ ราคา $611): estimate ~-35-40% ถ้า bear scenario

**CVaR (95%, 1-month estimated):**
```
μ_monthly ≈ 0.9% (= 11%/12)
σ_monthly ≈ 8.7% (= 30%/√12)
VaR 95% (1-month) = μ - 1.645σ = 0.9% - 14.3% = -13.4%
CVaR ≈ VaR × 1.25 = -16.8% (expected loss beyond VaR)
```

**ความหมาย:** ในเดือนที่แย่ที่สุด 5% ของ cases คาดว่า META จะขาดทุน -16.8%+ ต่อเดือน

### E. Kelly Criterion [CFA L3: Portfolio Management — Position Sizing]

*(ยังไม่เรียน — Kelly Criterion เป็น formula คำนวณสัดส่วน portfolio ที่ optimal สำหรับ bet/investment โดยใช้ Win/Loss ratio)*

**Full Kelly:**
```
Kelly % = (Win Rate × Avg Win - Loss Rate × Avg Loss) / Avg Win

ใช้ expected returns:
Win = Bull Case FV $850 / Current $611 - 1 = +39.1%
Loss = Bear Case FV $380 / Current $611 - 1 = -37.8%
Win Rate = Bull+Base probability = 80% (แยก loss = bear case 20%)

Kelly = (0.80 × 0.391 - 0.20 × 0.378) / 0.391
= (0.313 - 0.076) / 0.391
= 0.237 / 0.391
= 60.6%
```

**Full Kelly 60.6% = ไม่สมเหตุสมผล** (Kelly มักต้อง scale down เพราะ parameter uncertainty)

**Quarter Kelly: 60.6% / 4 = 15.2%** → แต่ IPS กำหนด max single position 8-10% ดังนั้น cap ที่ IPS

**Kelly Signal: Positive (ควร deploy) แต่ limited by IPS max position**

ในเชิง quant Kelly ไม่ได้บอกว่า "อย่าซื้อ" — บอกว่า "ซื้อได้ แต่ cap ที่ IPS"

### F. Forward Sharpe (Deploy Signal) [CFA L2: Portfolio Management — Sharpe Ratio]

**กรณีที่ Thesis ถูก (upside $639 base):**
```
Upside Return = ($639 - $611) / $611 = +4.6%
Time Horizon = 12 months
Forward Sharpe = (4.6% - 4.5%) / 30% = 0.003
```
**Forward Sharpe ที่ Base FV: 0.003 — ต่ำมาก (เกือบ zero)**

**กรณีที่ Include Momentum (upside $850 bull weighted 25% เพิ่ม):**
```
P-W Upside = ($640 - $611) / $611 = +4.7%
Forward Sharpe = (4.7% - 4.5%) / 30% = 0.007 — ยังต่ำ
```

**กรณีที่ใช้ Carhart Adjusted Return (16%):**
```
Forward Sharpe Adj = (16% - 4.5%) / 30% = 11.5% / 30% = 0.383
```
— ใกล้เคียง S&P 500 (0.45-0.55) แต่ยังต่ำกว่า

**Quinn's Deploy Signal Assessment:**
- Forward Sharpe บน Base FV ≈ 0 → ไม่น่าสนใจ ณ ราคา $611
- ถ้า META ย่อมาที่ $550-570 → Forward Sharpe ≈ 0.3+ = deploy zone
