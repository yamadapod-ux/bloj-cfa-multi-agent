## 2. Reverse DCF — ตลาด price-in อะไรที่ $256.20?

Market cap ~$2,764B ≈ EV ~$2,773B — เทียบ Emma's base-case EV (DCF $857-$1,092B, SOTP $1,314-$1,381B) → ตลาด price-in สูงกว่า Emma's SOTP (วิธี generous ที่สุด) ถึง **~2.0-2.1x**

ตีความได้ 3 ทาง (ไม่ exclusive กัน):
1. **Margin/growth เร็วกว่าที่ Emma สมมติมาก** — ตลาดอาจเชื่อ AWS margin ฟื้นเร็วกว่า + capex normalize เร็วกว่า scenario "fast" ของ Emma
2. **Reverse-WACC:** ถ้าใช้ EV/EBIT multiple ปัจจุบันของตลาด (EV/EBIT 30.11x ตาม stockanalysis.com) เทียบ consolidated EBIT $79,975M → ตลาด implied WACC ต่ำกว่า CAPM-beta มาก (~7-8%, ใกล้ risk-free+small premium) — sẽ pattern เดียวกับ SHOP/MELI ที่ทีมเคยพบ (ตลาด price ด้วย WACC ต่ำกว่าที่ beta บอก)
3. **Multiple expansion เพื่อ optionality อื่น** (Trainium/custom silicon, Anthropic stake ฯลฯ) ที่ไม่ได้อยู่ใน segment DCF/SOTP นี้

**Quinn's view:** ข้อ 2 (reverse-WACC) เป็นคำอธิบายหลักที่สม่ำเสมอกับ pattern อื่นในพอร์ต — ไม่ใช่หลักฐานว่า Emma ผิด แต่เป็น circular ถ้าใช้ตลาดพิสูจน์ตลาด (Bear ต้อง challenge ข้อนี้)

## 3. Forward Value Path — 2027 / 2029 / 2031 (base-case roll-forward)

ตอบคำถาม "มูลค่าวันนี้ (entry price ควรจ่าย) vs มูลค่าระยะยาว (ที่ธุรกิจโตไปถึง)" — ใช้ Emma's slow-normalization base DCF, roll-forward ตาม timeline:

| ปี | Forward Value/share | หมายเหตุ |
|---|---|---|
| **วันนี้ (2026)** | **$78.55-$100.4** (Base DCF range) | capex drag สูงสุด ณ จุดนี้ |
| **2027** | **≈$88.6** | capex เริ่ม normalize, FCFF พลิกบวก |
| **2029** | **≈$110.1** | margin ฟื้น, capex ต่อ revenue ลดลงมาก |
| **2031** | **≈$117.7** | เข้าสู่ Gordon-growth trajectory (TGR 3%) |

**Key message:** value **เพิ่มขึ้นตามเวลา** ($79→$89→$110→$118) สอดคล้องกับ thesis ว่า capex วันนี้จะ pay off ในระยะยาว — แต่ **แม้ถึงปี 2031 ค่ายังไม่ถึง $200** ภายใต้สมมติฐาน conservative/transparent นี้ — ต่างจาก hypothesis ของ CIO ที่ว่า AMZN ระยะยาวควรเกิน $200 — **รายงานตามจริง: ภายใต้ assumption เหล่านี้ forward value path ไม่ confirm hypothesis นั้น** (อาจเพราะ margin/growth path ที่ Emma สมมติ conservative เกินจริง — ดู caveat Emma §4)
