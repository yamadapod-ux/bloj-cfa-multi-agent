## 4. Sensitivity Matrix 5×5 — Subscriber Growth × ARPU [CFA L2: Equity Valuation — Sensitivity Analysis]

**เหตุผลที่เลือก 2 ตัวแปรนี้สำหรับ HIMS:**
- HIMS เป็น subscription business → Revenue = Subscribers × ARPU (Average Revenue Per User)
- **Subscriber Growth** = ตัวแปรหลักที่บ่งบอก demand + market share
- **ARPU** = ตัวแปรหลักที่บ่งบอก pricing power + product mix
- ทั้งสองตัวแปรมีความไม่แน่นอนสูงหลัง GLP-1 controversy

**สมมติฐาน:**
- Base Case Subscribers FY2025E: 1.1M active subscribers (จาก ~870K FY2024)

## 6. Position Sizing — Kelly Criterion [CFA L3: Portfolio Construction — Kelly Criterion]

**Kelly Formula:** f* = (bp - q) / b
- b = Win/Loss ratio (bull return / expected loss)
- p = Probability of win (bull case)
- q = 1 - p

**Parameter Estimation:**

| Scenario | Probability | Return |
|----------|------------|--------|
| Bull Case | 25% | +35% |
| Base Case | 45% | -22% |
| Bear Case | 25% | -50% |
| Extreme Bear | 5% | -75% |

**Probability-Weighted Return:** 
= (0.25 × 35%) + (0.45 × -22%) + (0.25 × -50%) + (0.05 × -75%)
= 8.75% - 9.9% - 12.5% - 3.75%
= **-17.4%** (Negative Expected Value!)

**Kelly Criterion ผลลัพธ์:** เมื่อ Expected Value ลบ → Kelly = 0% → **ไม่ควรลงทุนตามหลัก Kelly**

**Half-Kelly (Practical):** ถ้าจะลงทุนจริงๆ ด้วยเหตุผล speculative → Max 1–2% ของ portfolio
