```markdown
3. **Rf / ERP:** Rf = 10Y UST ณ วันวิเคราะห์ (≥2 sources) · ERP มี source (เช่น Damodaran implied ERP) — ห้าม carry forward จากรายงานเก่า
4. **External cross-check (บังคับ):** หา WACC หรือ cost of equity ที่แหล่งภายนอกใช้กับ ticker นั้น **≥3 แหล่ง** (เช่น Morningstar, AlphaSpread, GuruFocus, valueinvesting.io, stockanalysis, sell-side note) พร้อม URL

6. ห้ามเลือก WACC หลังเห็น FV — Atlas ล็อกค่าใน Data Package ก่อน Emma/Quinn/Bear เริ่ม

### Non-Operating Asset Bridge Rule (บังคับ — เพิ่ม 2026-10-08, ไม่ใช่ Return-side rule)

**ที่มา:** AMZN v1–v3.3 แปลง EV → Equity โดยหักแค่ net debt — ไม่ได้บวก Anthropic stake (~$190B ตาม 10-Q Q2/2026) [CFA L2: Equity — Free Cash Flow Valuation, non-operating assets]

1. **Equity value = EV (operating) + non-operating assets − debt − minority interest − preferred** — ทุกรายงาน
2. Non-operating assets = equity investments / stakes ในบริษัทอื่น, excess cash, marketable securities ที่ไม่อยู่ใน operating FCF · ใช้ **carrying/fair value ล่าสุดจาก 10-Q/10-K** (ระบุ line item + filing) ≥2 sources
3. **ภาษี:** หัก deferred tax liability ที่เกี่ยวข้องถ้าเปิดเผย · ถ้าไม่เปิดเผย ใช้ statutory 21% × (fair value − cost basis) และ flag
4. **ห้ามนับซ้ำ:** ถ้า income จากสินทรัพย์นั้นอยู่ใน FCF ที่ discount อยู่แล้ว ห้ามบวกซ้ำ — ต้องระบุ
5. ค่า bridge เป็น **ข้อเท็จจริงร่วม** — Atlas ใส่ใน Data Package, Emma/Quinn/Bear ใช้ค่าเดียวกัน (ไม่ใช่ความเห็นรายคน)

**Morgan:** ไม่มี bridge table / ไม่มี source filing / ใช้ค่าไม่ตรงกันระหว่าง analyst = `RULE_VIOLATION` · non-operating asset ≥5% ของ market cap แต่ไม่ถูกนับ = `DATA_ERROR`
```
