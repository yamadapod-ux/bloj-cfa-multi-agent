## 🏢 Business Deep Dive [CFA L2: Industry Analysis — Porter's Five Forces]

### How Does AMD Make Money?

1. **Data Center (AI GPU + EPYC CPU) — ~50-55% revenue, engine หลัก**
   - MI300X/MI350 Instinct series: GPU สำหรับ AI training + inference ขายให้ hyperscalers ราคา $10,000-15,000+/chip
   - EPYC GENOA/BERGAMO CPUs: ยึดตลาด x86 server CPU 32-34% จากเดิม <5% ในปี 2019
   - ลูกค้าหลัก: Microsoft Azure, Meta AI, AWS, Google Cloud (AI capex ทุก hyperscaler)

2. **Client/PC (Ryzen CPU + Radeon GPU) — ~25-28% revenue, slow recovery**
   - Ryzen 9000 series: PC processor ชั้นนำสำหรับ consumer + laptop
   - PC market recovering ช้าหลัง COVID boom ยุบ

3. **Embedded (Xilinx FPGAs/SoCs) — ~10-12% revenue, still recovering**
   - Xilinx acquisition $49B (2022) → FPGA market leadership
   - Automotive, Industrial IoT, Defense applications
   - Inventory digestion cycle — recovery underway แต่ยังช้า

4. **Gaming (Semi-custom APUs) — ~8-10% revenue, declining**
   - Sony PS5 + Microsoft Xbox ใช้ AMD APU (contract manufacturing)
   - Console cycle aging → declining segment
