# Investor Bootcamp — Journal

ดูหลักสูตรเต็มที่ `learning/investor_bootcamp.md` — ไฟล์นี้คือที่บันทึกทุกสัปดาห์ที่ทำ exercise จริง

**Format ต่อ entry:**
```
## Week N — [หัวข้อ] (วันที่ทำ)
**Predict ของฉัน:** ...
**สิ่งที่ทีม/ข้อมูลจริงบอก:** ...
**Gap / สิ่งที่พลาด:** ...
**สิ่งที่จะทำต่างไปครั้งหน้า:** ...
```

สำหรับสัปดาห์ที่ไม่มี Predict-then-Compare (เช่น Phase 0 บาง week ที่เป็น concept ล้วน) ใช้ format สั้นแทน:
```
## Week N — [หัวข้อ] (วันที่ทำ)
**สิ่งที่เรียนรู้:** ...
**คำถามที่ยังไม่ชัด:** ...
```
